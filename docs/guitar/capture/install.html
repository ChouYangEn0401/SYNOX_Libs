🎸 吉他抓譜書籤

把下面兩顆按鈕拖到瀏覽器的書籤列（手機：先在電腦加，再同步）。點書籤時只讀你正在看的那一頁，不上傳任何東西。

  • 🎸 Chordify→和弦
    在 Chordify 歌曲頁點：抓和弦格子、校正時間（按播放 15 秒）、下載 JSON
  • 🎸 YouTube→歌詞
    在 YouTube 影片頁點：抓字幕（或轉錄稿）的每一句時間、下載 JSON

流程

  1. Chordify 歌曲頁 → 點「Chordify→和弦」→「開始校正」→ 按播放 15 秒 →「停止並下載」
  2. 同一首歌的 YouTube 頁 → 點「YouTube→歌詞」→ 下載（沒有字幕時，先打開「顯示轉錄稿」再點一次）
  3. 兩個 JSON 拿到 SYNOX 吉他面板的「匯入」合併成一份歌（設計見 docs/adr/0007）

Chordify 的和弦是電腦聽出來的，常有錯；請只拿來自己練習，不要轉貼。
