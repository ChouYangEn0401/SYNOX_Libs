# ADR-0002：money 0.2——通用版記帳要補哪些、不補哪些

- 狀態：已採用（2026-11-13）
- 範圍：`packs/money`（0.1.1 → 0.2.0）

## 背景

money 0.1.1 只有四個指令（記一筆、最近幾筆、這個月、預算），一筆帳只有金額、類別文字、備註、時間；
所有東西都算「花掉的錢」，存錢、投資、收入都會被算進「這個月花了多少」。

維護者自己另外有一個功能完整、不公開的記帳工具（資料庫、網站、券商對帳等）。維護者的決定：
工具庫的 money **維持簡單**，多層預算、帳戶對帳這類完整功能不放進來；這裡只從那邊挑常用的小功能，
**只參考做法、用這個工具庫的寫法重寫**，不複製它的任何程式、資料或範本檔。

## 決定

### 1. 這次補的七件事

| # | 功能 | 指令／做法 |
|---|---|---|
| 1 | 資料加版本 | 存的 JSON 多 `"schema": 2`；每筆多 `id`（流水號，刪了不重用）、`kind`、`date`。讀到 0.1.x 的舊資料自己轉，下次寫入就存成第 2 版 |
| 2 | 使用者自己管類別 | `/money_cats`、`/money_cat_add`、`/money_cat_rm`。類別是使用者自己的資料（`pack.store.of(user)`），**程式不靠類別名字判斷任何事**，只看 `kind` |
| 3 | 中性範本 | 範本是 `pack.py` 裡的常數；**預設一個類別都沒有**，下 `/money_template <名字>` 才合併進去；同名的跳過，所以載兩次不會多、也不會蓋掉自己改過的 |
| 4 | 關鍵字猜類別 | 打的字不是自己的類別名、但含某個類別的關鍵字 → 用那個類別（最長的關鍵字優先）；猜不到就照打的字記；沒給類別＝「待分類」，不擋記帳 |
| 5 | 收入與轉帳 | `kind`：`expense`（支出）／`income`（收入）／`transfer`（轉帳）。存錢、投資、還款、繳卡費是轉帳，**不算「這個月花了」**、不吃預算 |
| 6 | 撤銷與刪除 | `/money_undo` 撤掉最後一筆（WRITE）；`/money_rm <編號>` 刪某一筆（DANGER，AI 一律送確認卡） |
| 7 | 篩選與單項上限 | `/money_list` 可以用關鍵字、類別、月份、種類篩；`/money_cap <類別> <金額>` 設某個支出類別每月的上限，只提醒、不擋 |

### 2. 範本

| 範本 | 內容 | kind |
|---|---|---|
| 基本 | 早餐、午餐、晚餐、點心宵夜、飲料（食）、衣著、居家、交通、學習、娛樂、醫療、其他 | 支出 |
| 帳單 | 房租、水電瓦斯、管理費、手機網路、訂閱 | 支出 |
| 存錢與投資 | 存錢、投資、還款、繳卡費（轉帳）；利息（支出） | 轉帳／支出 |
| 捐贈 | 捐款、十一奉獻 | 支出 |
| 收入 | 薪資、兼職、退款回饋、其他收入 | 收入 |

- 關鍵字只放通用詞，不放品牌、店名、電信業者、串流平台的名字（有地區與商標的味道；想要更準的人自己加）。
- 「捐贈」裡的「十一奉獻」是**作者刻意保留**的：這是作者自己會用的工具，作者選擇讓它留著作者的樣子。
  範本是選配的，不載就不會出現；其他範本只放通用詞。
- **信用卡不是類別**：刷卡是「用什麼付」，不是「買了什麼」。做法是付款方式（每筆可以加 `account=…`，只是標籤、不算餘額）
  ＋轉帳類「繳卡費」（不算花費），否則刷卡與繳卡費會重複算。
- 使用者可以在範本之外自己加、改、刪類別；範本只是起點。

### 3. 不補的（這次）

| 功能 | 為什麼 |
|---|---|
| 匯出 CSV | 要宣告 `filesystem:own`、改 `test_gates` 的允許清單；之後另外一個 commit |
| 固定項目（每期要記的帳） | pack 不能排程；之後再看要不要做「一鍵記下本期的固定項目」 |
| 每期從幾號開始 | 先維持日曆月 |
| 多層預算、薪水分配、帳戶餘額、信用卡帳單、分期、代墊、投資對帳 | 超出「簡單記帳」；要的人用完整版 |
| 看時間猜早午晚餐 | 先不做；關鍵字已經夠用 |
| CSV 匯入、收據附件 | 要先有「檔案放進使用者資料夾」的流程 |

### 4. 相容

- **升級**（0.1.x → 0.2.0）：讀的時候自己轉——每筆補 `id`（照原本的順序）、`kind=expense`、`date`（從 `at` 算）、補 `categories: []`；
  存的時候寫 `schema: 2`。舊欄位（`amount`、`category`、`memo`、`at`）都留著。
- **退回 0.1.1**：舊程式只看 `entries`／`budget`，多的欄位會被忽略，資料不會壞；但**收入與轉帳會被當成花費算進「這個月」**。
- 版本：`0.1.1 → 0.2.0`（加了指令、資料格式也升了）；`stage` 維持 `alpha`；`requires.sdk` 維持 `>=0.2,<0.3`（用到的介面 SDK 0.2.0 都有）。

## 考慮過但沒選的

| 做法 | 為什麼不選 |
|---|---|
| 第一次用就自動載入「基本」範本 | 使用者沒選就多一堆類別；類別應該是使用者自己放進去的 |
| 範本只寫在文件裡 | 要一行一行打 `/money_cat_add`，門檻太高 |
| 信用卡做成支出類別 | 刷卡與繳卡費會重複算 |
| 改成包那個完整版工具的 cli pack | 它要另一個 repo 的執行環境，工具庫打包不了；而且這裡要的就是簡單版 |
| 程式靠固定的類別名字（例如「繳卡費」）判斷 | 使用者改名就壞；改用每個類別自己的 `kind` |
