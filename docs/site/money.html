記帳

money · v0.2.0 · 群組：記帳

花了多少、賺了多少隨手記一筆，月底看錢都去哪了。

🧪 alpha 早期版 加密存在這台電腦 不連網 👥 伺服器版也能用：每人一份資料

指令

  • /money 120 午餐記一筆支出（類別可以不填）會寫入
  • /money_in 32000 薪資記一筆收入，不算花費會寫入
  • /money_transfer 5000 存錢記一筆轉帳（存錢、投資、繳卡費），不算花費、不吃預算會寫入
  • /money_month這個月花多少、照類別分，預算還剩多少唯讀
  • /money_list最近幾筆，可以用關鍵字、類別、月份篩唯讀
  • /money_undo撤銷最後記的那一筆會寫入
  • /money_rm 3刪掉某一筆（編號看 /money_list）危險：會先問你
  • /money_budget 20000設每月總預算（0＝拿掉）會寫入
  • /money_template 基本載入現成的類別範本（不給名稱＝列出有哪些）會寫入

還有單一類別的上限、自己加刪類別與關鍵字、補記別天的帳等，見 README。

直接跟 AI 說

午餐 120→ 記一筆支出
薪水進來 32000→ 記一筆收入
這個月花多少？→ 照類別列出來
剛剛那筆記錯了→ 撤銷最後一筆

怎麼裝

  1. 拿到 money-0.2.0.synoxpack

    直接下載（GitHub 發佈頁 v0.2.0）；要一次拿全部工具就下載 tools-0.2.0.zip，解開放進 SYNOX 資料夾的 tools\。也可以用工具庫的 scripts\build.py money 自己打包。

  2. 點兩下，或拖進 SYNOX 網頁

    也可以 python -m synox tools install money。

  3. 看完檢查報告，按確認

    裝好後打 /help 就多一頁「💰 記帳」。

資料與安全

  • 🔒存在哪：data/money.json.enc，保管箱加密；帳、類別、關鍵字都只在你自己那一份。
  • 🌐連不連網：不連網、不開別的程式。
  • ⚠️危險動作：/money_rm 刪掉一筆帳，AI 要做會先送確認卡。
  • 👥伺服器版：成員也能用，每個人一份帳，互相看不到。
  • ↩️從 0.1.x 升上來：舊的帳自動補上編號、日期、種類，不用做什麼。退回 0.1.1 資料不會壞，但收入和轉帳會被當成花費。

現在的狀態

  • 🧪 未實測還沒有人長時間實際用過（所以標 alpha）；指令與資料格式之後可能會改。
  • 自動測試：tests/test_money.py 22 個全過：記支出／收入／轉帳、預算與類別上限的提醒、類別與範本、用關鍵字猜類別、補記別天、撤銷與刪除、篩選、舊資料升級，以及資料加密、每個人的帳互相看不到。另外有所有工具共用的安全檢查與打包測試。
