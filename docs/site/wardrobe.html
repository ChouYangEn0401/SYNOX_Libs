幫 SYNOX 換一套衣服

挑一套喜歡的，下載它的 .synoxpack。換上之後，整個聊天畫面的顏色、吉祥物、開場動畫都跟著換。不喜歡隨時換回來；SYNOX 預設的樣子不會被改掉。

  • 每一套只有圖和顏色（SVG 和 CSS），不帶任何程式，也不連網。
  • 每一套都有淺色和深色兩種；右上角的 ◐ 可以切換這一頁看看。
  • 字型沒有附在檔案裡：電腦上沒有那個字型時，介面文字會用系統字；SYNOX 字標和開場的字是畫好的圖，不受影響。

怎麼換

  1. 1. 下載在下面挑一套，按「下載 .synoxpack」（直接從這一頁下載；之後也會放上 GitHub 發佈頁 v0.2.0）。
  2. 2. 裝進 SYNOX打開 SYNOX 的網頁介面，「設定 → 🧩 功能與安裝」，選剛下載的 .synoxpack。SYNOX 會先給你看安全檢查報告（淺色／深色的色票、預覽），按「確認安裝」才會裝。
  3. 3. 換上裝好不會自己換：到「設定 → 🎨 外觀」挑它、看預覽，按「套用」。不喜歡，同一頁按「換回原本的 SYNOX」就好。

系列 V · costume-v-kintsugi

維維

下載 .synoxpack
要注意
  • 分裂和展開的細節要 64px 以上才看得清楚，所以 App 圖示維持只放 V 徽章，16px 也清楚。
  • 臉只有兩顆金色的眼睛燈，沒有嘴巴，表情靠眼睛的形狀和身體的變形來演：比小動物那幾組酷，但不會撒嬌。
  • 變形動畫好看但不能一直播，實際產品裡建議只有「開場」和「等你確認」播完整版，其他時候用短的。
