怎麼裝

  1. 先裝好 SYNOX

    還沒有的話看 SYNOX 介紹頁的「三步就能用」。

  2. 下載工具

    要一個就在上面點進去下載那一個 .synoxpack；要全部就下載 tools-0.2.0.zip，解開放進 SYNOX 資料夾、叫 tools。

  3. 點兩下，或拖進 SYNOX 網頁，看完報告按確認

    放了 tools 資料夾的，也可以 python -m synox tools list 看有哪些、python -m synox tools install notes money 挑著裝。每條路都過同一套安全檢查。

穩定度

🔧 test只給開發者試，隨時會改
🧪 alpha能用，但還沒在真的環境長時間用過。目前全部工具都在這一級。
🚧 beta功能齊了、有人實際用過一陣子
⭐ stable長時間實際使用過、有測試

現在的狀態

  • 🧪 未實測接外面服務的 4 個（Notion、Todoist、Google 日曆、Apple 提醒事項）只用模擬的連線測過，還沒對真的服務長時間用過。
  • 🧪 未實測另外 5 個還沒有人長時間實際用過，指令與資料格式之後可能會改。
  • 自動測試：281 個，2026-11-13 在 Linux 雲端全部通過（用的是假的 SYNOX 對話、假的外部服務）。
  • Apple 提醒事項：iCloud 升級過的提醒事項 Apple 不開放外部程式讀，要改用別家的 CalDAV 帳號。

想自己寫一個工具？

寫一個函式就是一個工具，打包成 .synoxpack 就能給別人裝。說明在 SYNOX 的 docs/tools.md； 這個工具庫怎麼測試、打包，看 README 的「給開發者」。
