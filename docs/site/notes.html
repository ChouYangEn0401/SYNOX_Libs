隨手記

notes · v0.1.1 · 群組：入門

想到什麼就記一筆，之後找得到、刪得掉。

🧪 alpha 早期版 加密存在這台電腦 不連網 👥 伺服器版也能用：每人一份資料

指令

  • /note 買牛奶記一筆會寫入
  • /note_list 牛奶列出全部，或只列含關鍵字的唯讀
  • /note_rm 3刪掉一筆（編號看 /note_list）會寫入
  • /note_clear全部刪掉危險：會先問你

直接跟 AI 說

幫我記一下：買牛奶→ 記一筆
我記過什麼跟牛奶有關的？→ 用關鍵字找
筆記全部刪掉→ 先送確認卡，你按了才刪

怎麼裝

  1. 拿到 notes-0.1.1.synoxpack

    直接下載（GitHub 發佈頁 v0.2.0）；要一次拿全部工具就下載 tools-0.2.0.zip，解開放進 SYNOX 資料夾的 tools\。也可以用工具庫的 scripts\build.py notes 自己打包。

  2. 點兩下，或拖進 SYNOX 網頁

    也可以 python -m synox tools install notes。

  3. 看完檢查報告，按確認

    裝好後打 /help 就多一頁「📒 隨手記」。

資料與安全

  • 🔒存在哪：data/notes.json.enc，保管箱加密；金鑰在 Windows 上綁這個帳號。
  • 🌐連不連網：不連網、不開別的程式。
  • ⚠️危險動作：/note_clear 一次刪光，AI 要做會先送確認卡。
  • 👥伺服器版：每個人一份筆記，互相看不到。

現在的狀態

  • 🧪 未實測還沒有人長時間實際用過（所以標 alpha）；指令與資料格式之後可能會改。
  • 自動測試：tests/test_notes.py 1 個：記兩筆、用關鍵字找、刪不存在的和存在的、確認存檔是加密的。/note_clear 沒有專門的測試。另外有所有工具共用的安全檢查與打包測試。
