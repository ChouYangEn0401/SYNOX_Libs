Notion

notion · v0.1.1 · 群組：接外面的服務

在 Telegram 說一句話，就能找、讀你的 Notion 頁面，或往裡面加東西。

🧪 alpha 早期版 token 加密存在這台電腦 只連 Notion 官方 API 👤 單人用：只有安裝的人能用

指令

  • /notion 會議用標題搜尋頁面唯讀
  • /notion_read 買牛奶讀一頁：標題、欄位、內文唯讀
  • /notion_dbs列出分享給 SYNOX 的資料庫唯讀
  • /notion_rows 任務資料庫最近改過的幾列唯讀
  • /notion_row 任務 買牛奶 props=狀態:待辦; 日期:明天在資料庫加一列（props= 可以不寫）會寫入
  • /notion_new 上層頁面 標題 text=內文在某一頁底下開新頁會寫入
  • /notion_append 頁面 要加的字在一頁最後面加一段字會寫入
  • /notion_set 頁面 狀態:完成改一頁（資料庫的一列）的欄位危險：會先問你
  • /notion_token設定 token（只收私訊，AI 不能用）會寫入
  • /notion_status看有沒有接上唯讀
  • /notion_logout把 token 拿掉會寫入

要先準備

  1. 在 Notion 建一個 integration

    用電腦開 Notion 的 integrations 設定頁 → 新增，名字取「SYNOX」，類型選 Internal。功能勾讀取、插入、更新內容（只想讓它看就只勾讀取）。

  2. 複製它的 Internal Integration Secret

    ntn_ 開頭的一長串，就是 token。

  3. 私訊 bot 打 /notion_token，照指示貼上

    看到「✅ 接上 Notion 了」就好。token 不要貼在一般聊天或給 AI；貼完把那則訊息刪掉（Telegram 不是端對端加密）。更保險：在這台電腦開 Console.bat 打 /notion_token。

  4. 把頁面分享給 integration

    最常忘的一步：Notion 頁面右上角 ⋯ → 連接 → 選「SYNOX」。沒分享的頁面它看不到。

直接跟 AI 說

Notion 裡有沒有寫過會議記錄？→ 搜尋頁面
在任務資料庫加一筆：買牛奶，狀態待辦，明天→ 加一列
在購物清單那頁最後面補一句：還要蛋→ 在頁面後面加字
把買牛奶改成完成→ 先送確認卡，你按了才改

怎麼裝

  1. 拿到 notion-0.1.1.synoxpack

    直接下載（GitHub 發佈頁 v0.2.0）；要一次拿全部工具就下載 tools-0.2.0.zip，解開放進 SYNOX 資料夾的 tools\。也可以用工具庫的 scripts\build.py notion 自己打包。

  2. 點兩下，或拖進 SYNOX 網頁

    也可以 python -m synox tools install notion。

  3. 看完檢查報告，按確認

    裝好後照上面「要先準備」接上 Notion，打 /help 就多一頁「🗂 Notion」。

資料與安全

  • 🔒token 存在哪：data/notion.json.enc，保管箱加密；不在 config.json，log 裡會遮成 ntn_***。
  • 🌐連不連網：只連 api.notion.com（Notion 官方 API），不開網路埠、不跑別人的程式；只看得到你分享給 integration 的頁面。
  • 🤖AI 看得到什麼：AI 讀到的頁面內容會送到你設定的 AI 供應者。頁面裡夾的「指令」只當資料，不會照做。
  • ⚠️危險動作：/notion_set 會改既有內容，AI 要做會先送確認卡。
  • 👥誰能用：只有安裝時配對的擁有者；伺服器版的成員、訪客用不到。
  • 🚪不想用了：/notion_logout，再到 Notion 把 integration 刪掉，token 就徹底失效。

現在的狀態

  • 🧪 未實測還沒對真的 Notion 長時間用過：只用假的連線測過（所以標 alpha）；指令之後可能會改。
  • 改不了的欄位：人、關聯、檔案、公式欄位要在 Notion 裡改；一次加的字只有一段。
  • 自動測試：tests/test_notion.py 18 個，全部通過（用假的 Notion 連線，不連網）：設定與拿掉 token、token 加密且不進 log、別人和 AI 不能碰 token 指令、搜尋／讀／列資料庫、加一列、開新頁與補字、錯誤訊息是中文、AI 改欄位要先按確認卡、頁面內容當資料包起來。打字直接用 /notion_set 沒有專門的測試。另外有所有工具共用的安全檢查與打包測試。
