Apple 提醒事項

apple-reminders · v0.1.1 · 群組：接外面的服務

在 SYNOX 裡看、加、打勾 iPhone 提醒事項 App 裡的事。先看這句：iCloud 的提醒事項如果升級過（iOS 13 之後幾乎每個人都是），Apple 不開放給外面的程式，這個工具讀不到也加不進去；要用得接一個別家的 CalDAV 帳號。

🧪 alpha 早期版 帳號加密存在這台電腦 會連網：只連你設定的伺服器 👤 單人用：只有安裝的人能用

指令

  • /applerem 工作列出還沒完成的（照到期排序，最多 30 項）；不寫清單＝全部唯讀
  • /applerem_lists有哪些提醒事項清單唯讀
  • /applerem_add 繳電費 due=明天 15:00加一個；有時間的會帶到時提醒，可加 list=清單會寫入
  • /applerem_done 2打勾（編號看上一次 /applerem）會寫入
  • /applerem_status看帳號（遮住）、測試連線；AI 不能用唯讀
  • /applerem_logout清掉這台電腦存的帳號；AI 不能用會寫入

要先準備

  1. 一個能用 CalDAV 的提醒事項帳號

    建議：在 iPhone 的「設定 → 提醒事項 → 帳號 → 加入帳號 → 其他 → 加入 CalDAV 帳號」接一個別家的帳號（例如 Fastmail、mailbox.org、自架 Nextcloud），清單會出現在 iPhone 提醒事項 App。iCloud 只有從沒升級過的提醒事項能用，而且 Apple 隨時可能關掉。

  2. 準備密碼

    iCloud 要用 App 專用密碼（appleid.apple.com → 登入與安全性 → App 專用密碼），不是 Apple ID 本身的密碼。

  3. 在這台電腦雙擊 Connect-Apple.bat

    工具裝好後，在 SYNOX 資料夾裡找到它（或 python -m synox connect apple-reminders），填伺服器網址（一定要 https://）、帳號、密碼。不能在聊天裡登入。

  4. 打 /applerem_status

    測試登入、列出找到的清單；iCloud 升級過的話它會說明為什麼找不到。

直接跟 AI 說

我 iPhone 上還有哪些提醒？→ 列出還沒完成的
提醒我明天下午三點繳電費→ 加一個，到期明天 15:00
第 2 個做完了→ 打勾上一次列出的第 2 項

怎麼裝

  1. 拿到 apple-reminders-0.1.1.synoxpack

    直接下載（GitHub 發佈頁 v0.2.0）；要一次拿全部工具就下載 tools-0.2.0.zip，解開放進 SYNOX 資料夾的 tools\。也可以用工具庫的 scripts\build.py apple-reminders 自己打包。

  2. 點兩下，或拖進 SYNOX 網頁

    也可以 python -m synox tools install apple-reminders。

  3. 看完檢查報告，按確認

    裝好後打 /help 就多一頁「🍎 Apple 提醒事項」；接著照上面「要先準備」設定帳號。

資料與安全

  • 🔒存在哪：帳號存在 data/apple-reminders.auth.json.enc，保管箱加密；提醒事項本身留在 CalDAV 伺服器上。
  • 🌐連不連網：會連網，只連 https、只連你設定的那台主機（iCloud 允許 *.icloud.com），不跟隨重新導向，每次最多等 20 秒。
  • 🛡️伺服器回的東西：回應上限 5 MB，含 DOCTYPE／ENTITY 的 XML 拒讀；你打的字跳脫後才寫進去。
  • ⚠️危險動作：沒有。/applerem_logout 只清這台電腦存的帳號，記得也到 appleid.apple.com 撤銷那組 App 專用密碼。
  • 👥伺服器版：只給擁有者用（access: owner），只在私訊裡。

現在的狀態

  • 🧪 未實測還沒對真的 CalDAV／iCloud 伺服器跑過，測試全部用假的 HTTP 傳輸（所以標 alpha）。
  • Apple 的限制：升級過的 iCloud 提醒事項用不了，這不是這個工具能修的；重複的提醒事項不能在這裡打勾，要在 iPhone 上做。
  • 自動測試：tests/test_apple_reminders.py 24 個，全部通過：安裝檢查、存帳號（密文）、密碼錯、升級過的 iCloud 說明、列出／加入／打勾（含跳脫、到時提醒、重複項目、版本衝突）、只連設定的主機、拒絕 http、XML 與過大回應、日期解析。/applerem_lists 沒有專門的測試。
