Google 日曆

google-calendar · v0.1.1 · 群組：接外面的服務

直接看、加、刪你自己真正的 Google 日曆；跟只存在這台電腦的「行事曆」（/cal）不一樣。

🧪 alpha 早期版 授權加密存在這台電腦 會連網（只連 Google） 👤 單人用：只有安裝的人能用

指令

  • /gcal 明天 14:00 看牙醫加一個行程（也收 location=、note=）會寫入
  • /gcal_today今天的行程唯讀
  • /gcal_week這 7 天的行程唯讀
  • /gcal_list 10接下來的幾個行程（預設 10 個）唯讀
  • /gcal_rm 3刪掉一個（編號是最近一次列出來的）危險：會先問你
  • /gcal_status連上了沒、唯讀還是可以寫唯讀
  • /gcal_setup開始連接：填用戶端 ID、密鑰，拿登入連結（只有你能打）會寫入
  • /gcal_code貼回登入後瀏覽器網址列的整串網址（只有你能打）會寫入
  • /gcal_token（進階）直接貼 refresh token（只有你能打）會寫入
  • /gcal_logout中斷：刪掉授權、請 Google 收回（只有你能打）會寫入

要先準備

  1. 在 Google Cloud 建自己的用戶端

    開一個專案、啟用 Google Calendar API、設定 OAuth 同意畫面，建一個「電腦版應用程式」用戶端，拿到用戶端 ID 和密鑰。免費、不用信用卡；詳細步驟見 README。

  2. 打 /gcal_setup <用戶端 ID> <用戶端密鑰>

    只想讓 SYNOX 看、不能改：最後加 readonly。建議在這台電腦的 SYNOX 終端機或網頁打，不要用 Telegram。

  3. 打開它給的連結，登入、同意

    最後瀏覽器顯示「無法連上這個網站」是正常的。連結 15 分鐘內有效。

  4. 把網址列整串貼回來：/gcal_code <網址>

    看到「✅ 連上 Google 日曆了」就好了。同意畫面停在「測試」狀態的話，Google 每 7 天會讓授權失效。

直接跟 AI 說

Google 日曆今天有什麼？→ 列出今天的行程
幫我在 Google 日曆加：明天下午兩點看牙醫→ 加一個行程
把 Google 日曆上看牙醫那個刪掉→ 先列出來找編號，送確認卡，你按了才刪

怎麼裝

  1. 拿到 google-calendar-0.1.1.synoxpack

    直接下載（GitHub 發佈頁 v0.2.0）；要一次拿全部工具就下載 tools-0.2.0.zip，解開放進 SYNOX 資料夾的 tools\。也可以用工具庫的 scripts\build.py google-calendar 自己打包。

  2. 點兩下，或拖進 SYNOX 網頁

    也可以 python -m synox tools install google-calendar。

  3. 看完檢查報告，按確認

    裝好後打 /help 就多一頁「📅 Google 日曆」；再照上面「要先準備」連上。

資料與安全

  • 🔒存在哪：用戶端 ID／密鑰和 token 都在 data/google-calendar.json.enc，保管箱加密；不寫進設定檔或 log。行程本身留在 Google。
  • 🌐連到哪：只連 Google 的登入、換 token 和日曆 API；不在你電腦上開網路埠（登入後由你把網址貼回來）。
  • 🤖AI 碰不到憑證：連接用的四個指令只有你能打；AI 只能看、加、刪行程。
  • ⚠️危險動作：/gcal_rm 刪的是雲端上的行程，AI 要刪會先送確認卡。
  • 👥伺服器版：只給擁有者；其他成員看不到這個工具。

現在的狀態

  • 🧪 未實測還沒對真的 Google 日曆長時間用過：目前只用假的連線測過（所以標 alpha）。
  • 🧪 未實測登入轉址的網址（http://127.0.0.1:47231/）Google 會不會接受，是照 Google 的文件推斷的，還沒真的試過。
  • 自動測試：tests/test_gcal.py 25 個，全部通過：涵蓋登入流程（貼網址、state 不對或過期、貼 refresh token）、看今天／這週、加行程、刪行程、唯讀模式、token 過期自動更新、AI 拿不到憑證指令、刪除要先確認、伺服器版成員看不到。全部用假的 HTTP，不連 Google。
