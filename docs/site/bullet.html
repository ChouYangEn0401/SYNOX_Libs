子彈筆記

bullet · v0.1.1 · 群組：規劃

子彈筆記是一種用簡單符號（• 要做的事、○ 事件、– 想法）快速記下每一天的手帳方法；這個工具幫你記今天、看整個月，並把沒做完的事搬到今天。

🧪 alpha 早期版 加密存在這台電腦 不連網 👥 伺服器版也能用：每人一份資料

指令

  • /bj • 買牛奶記一筆到今天（• 任務、○ 事件、– 筆記；沒寫符號就看字猜）會寫入
  • /bj_today看今天的記錄唯讀
  • /bj_month 2026-10月誌：這個月每一天＋還沒做完的任務（不寫月份＝這個月）唯讀
  • /bj_migrate以前沒做完的任務一件一件按按鈕：搬到今天／已完成／不做了／略過會寫入
  • /bj_done 1任務打勾（編號看 /bj_today）會寫入

還有刪掉一筆的 /bj_rm、主題清單（像書單）的 /bj_col，見 README。

直接跟 AI 說

記到手帳：今天 3 點和客戶開會→ 記一筆事件
把沒做完的搬過來→ 送一張有按鈕的卡，你自己一件一件按
把《原子習慣》加到書單→ 記進「書單」主題清單

怎麼裝

  1. 拿到 bullet-0.1.1.synoxpack

    直接下載（GitHub 發佈頁 v0.2.0）；要一次拿全部工具就下載 tools-0.2.0.zip，解開放進 SYNOX 資料夾的 tools\。也可以用工具庫的 scripts\build.py bullet 自己打包。

  2. 點兩下，或拖進 SYNOX 網頁

    也可以 python -m synox tools install bullet。

  3. 看完檢查報告，按確認

    裝好後打 /help 就多一頁「• 子彈筆記」。

資料與安全

  • 🔒存在哪：data/bullet.json.enc，保管箱加密。
  • 🌐連不連網：不連網、不開檔、不開別的程式。
  • ⏳遷移卡片：按鈕 24 小時後過期；別人按你的卡片不會生效。
  • 👥伺服器版：每個人一份手帳，互相看不到。

現在的狀態

  • 🧪 未實測還沒有人長時間實際用過（所以標 alpha）；指令與資料格式之後可能會改。
  • 🧪 未實測網頁「今天」面板：只測了它回傳的資料，沒在真的瀏覽器裡看過畫面。
  • 自動測試：tests/test_bullet.py 8 個，全部通過：猜分類、記錄／打勾／刪除、遷移按鈕（含 24 小時過期、別人按不了）、月誌與主題清單、伺服器版每人分開。遷移卡上的「✗ 不做了」按鈕沒有專門的測試。另外有所有工具共用的安全檢查與打包測試。
