diary · v0.1.0-alpha.1 · 群組：日記

挑一個題組，多半用勾的就寫完；寫完做成一頁 HTML，或一張像日記本內頁的卡片。靈修那一套是完整的，也有不談信仰的。

🧪 alpha 早期版 還沒在真的 SYNOX／Telegram 上實機試過 加密存在這台電腦 不連網 👥 伺服器版也能用：每人一份日記

指令

  • /diary 今天很好記成今天「隨手記」的新的一則，不蓋掉之前的會寫入
  • /diary_put 2026-11-02 three-lines 下雨寫進某一天、某個題組（只填空著的題目；也收 JSON 一次填好幾題）會寫入
  • /diary_show 2026-11-02那一天寫了什麼；給編號就看那一篇唯讀
  • /diary_list最近寫過的：日期、題組、字數、編號唯讀
  • /diary_templates有哪些題組；可以照「幾段式、要不要信仰、走哪些步驟」篩唯讀
  • /diary_suggest 今天很累但很感謝替一段話挑題組，附理由（照規則，不叫模型）唯讀
  • /diary_export today jot做成一頁 HTML ＋ 一張卡片 SVG，直接傳給你唯讀
  • /diary_overwrite today capsule a_verse user {…}換掉已經寫過的一兩題（只動點名的）危險：會先問你
  • /diary_rm 12刪一篇（進垃圾桶，/diary_undelete 救得回來）危險：會先問你
  • /diary_history 12一篇的歷史版本，/diary_restore 放回去唯讀
  • /diary_backup整本備份一份（寫入時也會每 6 小時自動留一份）會寫入
  • /diary_export_all整本匯出成 JSON 傳給你；只有你本人能用，AI 碰不到唯讀

另外還有取標題、換題組、垃圾桶、匯入、自己的題組與版型、設定、起始組合，共 37 個指令；完整表在 README。

直接跟 AI 說

記一下：今天下午雨停了→ 原話記成一則，不潤飾
幫我把今天整理成日記→ 先挑兩三個題組給你選；整理過的標「AI 整理」、附你的原文
把今天做成一張圖→ 傳一頁 HTML 和一張卡片給你
經文那題補上原文→ 只換那一題，先送確認卡

題組與輸出

  • 📖內建 41 個題組：與神同行（讀經、省察、禱告、代禱、講道與小組筆記、哀歌）、心情與難處、成為什麼樣的人、工作與創業、簡單記一下。29 個預設就出現，另外 12 個用 /diary_tpl_restore 拿出來。
  • ☑️七種題型：多行、條列、單行、單選、多選、程度、填空句（{} 是空格）。空的題目輸出時不會出現。
  • 📄頁面：信箋、對帳、稿紙、明信片四種版型，五種紙張顏色，可以加一張要點開的封面。
  • 🗒卡片：橫線、方格、點陣、空白四種紙，文字坐在橫線上；寬度 480–2400。
  • 🚫不需要 API key：輸出、挑題組、畫圖 prompt 都照規則做，不叫模型。

怎麼裝

  1. 拿到 diary-0.1.0-alpha.1.synoxpack

    直接下載（GitHub 發佈頁 v0.2.0）；要一次拿全部工具就下載 tools-0.2.0.zip，解開放進 SYNOX 資料夾的 tools\。也可以用工具庫的 scripts\build.py diary 自己打包。

  2. 點兩下，或拖進 SYNOX 網頁

    也可以 python -m synox tools install diary。

  3. 看完檢查報告，按確認

    裝好後打 /help 就多一頁「📔 日記」。想要不談信仰的起始題組：/diary_setup_init generic。

資料與安全

  • 🔒存在哪：data/diary.json.enc（日記與歷史版本）、data/diary.setup.json.enc（設定、自己的題組）、data/diary.backup-*.json.enc（整本備份），都是保管箱加密。
  • 📤輸出的檔：寫在你自己的資料夾、傳給你之後就刪。
  • 🌐連不連網：不連網、不開別的程式。
  • ⚠️危險動作：換掉寫過的題目、刪日記、永久刪除、還原備份，AI 要做會先送確認卡；整本匯出與匯入只給你本人。
  • 👥伺服器版：每個人一本日記、自己的題組與設定，互相看不到。

現在的狀態

  • 🧪 alpha剛從「每日日記」搬進來，還沒有人在 SYNOX 上實際用過；指令與資料格式之後可能會改。
  • 🧪 未實測只在測試裡跑過：還沒在真的 SYNOX／Telegram 上實機試過（版本號因此是 0.1.0-alpha.1）。
  • 沒有搬的：原本的網頁編輯器（三欄、換色、題組編輯器）、「用 AI 設計新版型」與「AI 取名」（要 Anthropic 的 key）；PNG 要用瀏覽器打開卡片後截圖。
  • 自動測試：tests/test_diary.py（寫入的規則、垃圾桶、歷史、備份、輸出、題組、設定、權限、伺服器版每人一份、密文）；tests/test_diary_parity.py 拿原本程式錄下的答案逐字比對（95 頁 HTML、60 張卡片、挑題組、23 次寫入）。
