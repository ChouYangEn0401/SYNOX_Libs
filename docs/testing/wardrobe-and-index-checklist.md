# 真機人工驗證清單：公開衣櫃頁＋工具庫列表的警告

> **全部勾完才算過關。** 任何一格是「失敗」或空白，這一輪就不算過；修好之後，失敗的那一項（和它影響到的項目）要重新驗一次、重新填。
>
> 自動測試（`pytest`、`build.py --check`、`build_costumes.py check`）測不到「真的瀏覽器裡動畫看起來對不對」，
> 也測不到「SYNOX 網頁真的把清單上的警告畫出來」，所以這幾項一定要人在真機上看。

## 怎麼填

- 每一項先照「步驟」做，對照「預期」，在結果表填：**結果**（通過／失敗）、**日期**（YYYY-MM-DD）、**驗證者**（代號就好，不寫真名）、**備註**（失敗時寫看到什麼；有截圖寫檔名）。
- 一項裡每一個瀏覽器都通過，才把那一項的核取方塊打勾。
- 瀏覽器：**Chrome**、**Edge**、**Firefox**（桌機，最新版）、**手機 Safari**（iPhone，最新版 iOS）。版本號寫進備註。
- 頁面：公開衣櫃頁＝claude.ai 上的 Artifact（網址見 [`docs/artifacts.json`](../artifacts.json) 的「SYNOX 衣櫃」），內容是 `docs/site/wardrobe.html` 產生的（`python scripts/build_costumes.py page`）。
  先確認線上頁的頁尾「頁面版本」跟本機 `docs/site/wardrobe.html` 一樣，不一樣就是線上還沒重新發佈，先發佈再驗。
- 「減少動態效果」怎麼開：Windows「設定 → 協助工具 → 視覺效果 → 動畫效果」關掉；iPhone「設定 → 輔助使用 → 動態效果 → 減少動態效果」打開；
  Firefox 也可以在 `about:config` 把 `ui.prefersReducedMotion` 設成 `1`。

## B. 工具庫列表顯示警告（pack.json 的 `warnings`）

現在沒有任何正式工具帶警告，所以要用**測試用的假工具**驗：在自己的分支或 worktree 裡，找一個工具複製成假工具（名字例如 `fake-risky`、版本 `0.0.1-alpha.1`），
在它的 `pack.json` 加：

```json
"warnings": [{"code": "vendor_no_security_guarantee", "text": "官方不保證安全", "advice": "建議在 docker 或 sandbox 執行"}]
```

再 `python scripts/build.py --out <暫存資料夾>` 打包（`dist/` 不 commit）。**測完把假工具刪掉，不要合併、不要發佈。**
SYNOX 用測試用的資料夾，不要用平常有真實資料的那一份。不開對外的網路埠。
