# ✅ todo（待辦）

| 指令 | 做什麼 |
|---|---|
| `/todo <內容>` | 加一項：`/todo !! 繳電費 明天 #家事`（`!` 重要、`!!` 很重要；`#標籤` 當專案；到期寫在句子裡） |
| `/todo_list [all\|today\|overdue\|#標籤]` | 不寫＝還沒做完的；`today` 今天到期、`overdue` 逾期、`all` 含做完的、`#家事` 只看那個專案 |
| `/todo_done <編號>` | 打勾完成 |
| `/todo_rm <編號>` | 刪掉一項 |
| `/todo_clear_done` | 清掉全部已完成的（⚠️ 危險：AI 要做會先送確認卡） |

- 到期跟行事曆同一套中文日期（明天、下週一、11/20、15號、下午3點…）；只寫時間＝今天。
- 清單排序：有期限的在前（越早越前）、同一天重要的在前；逾期的標 ⚠️。
- 網頁介面的工具頁有「逾期／今天／之後」面板（`GET /api/packs/todo/today`）。

資料：`data/todo.json.enc`（保管箱加密；伺服器版每人一份）。不連網、不開檔、不開別的程式（`capabilities: []`）。

**個人版與伺服器版**：伺服器版每人一份（`data/users/<id>/todo.json.enc`，用每個人自己的金鑰加密），別人的指令、面板、AI 都看不到；但伺服器的管理者有主金鑰，**解得開每個人的資料**。個人版改成伺服器版時，舊資料不會自己搬（[ADR-0003](../../docs/adr/0003-personal-and-server-mode.md)）。
