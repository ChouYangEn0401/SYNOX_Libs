# ✅ 待辦

## 什麼時候用
- 「提醒我明天要繳電費」「待辦：回信給房東」「很重要，週五前交報告」→ `todo__add`。
- 「我還有什麼沒做」→ `todo__list`（不填 `filter`）；「今天要做什麼」→ `filter=today`；「有什麼逾期了」→ `filter=overdue`；
  「家事有哪些」→ `filter=#家事`；「全部（含做完的）」→ `filter=all`。
- 「電費繳了」「第 3 個做完了」→ 先 `todo__list` 找到編號，再 `todo__done`（`n` 是 `[3]` 裡的數字）。
- 「把那個刪掉」→ `todo__rm`。只刪他指定的那一項。
- 「把做完的清掉」→ `todo__clear_done`。這是危險動作，系統會先送確認卡給使用者按，你不用再問一次。

## 怎麼填 `todo__add`
- `text` 放要做的事（保留使用者的說法，不要改寫）。
- 到期放 `due`：可以是 `2026-11-20`、`2026-11-20 15:00`，或「明天」「下週一」「11/20」「15號」（跟行事曆同一套）。沒期限就不填。
- 重要度放 `priority`：`2`＝很重要／緊急、`1`＝重要、不填＝普通。使用者沒說重要就不要自己加。
- 專案或分類寫成 `#標籤` 放進 `text` 裡（例：`text=買燈泡 #家事`）。
- 人打字時也可以直接 `/todo !! 繳電費 明天 #家事`（`!`／`!!` 是重要度）。

## 注意
- 有固定時間、要「到場」的事（開會、看醫生、聚餐）→ 用行事曆 `cal__add`；兩邊都要就兩個都加。
- 純粹想記下來、不用打勾的想法 → 用隨手記 `note__add`。
- 待辦加密存在使用者自己的電腦上。
