# 📅 calendar（行事曆）

| 指令 | 做什麼 |
|---|---|
| `/cal <時間 標題>` | 加一個行程：`/cal 明天 14:00 看牙醫`、`/cal 下週一下午三點半 開會 location=三樓`、`/cal 11/20 整天 員工旅遊` |
| `/cal_today` | 今天的行程 |
| `/cal_week` | 今天起 7 天的行程 |
| `/cal_list [n]` | 接下來的 n 個行程（預設 10） |
| `/cal_rm <編號>` | 刪掉一個（編號是清單上的 `[3]`，固定不變） |
| `/cal_ics` | 整本行事曆匯出成 `.ics` 檔，在 Google 日曆（設定 → 匯入與匯出）或 iPhone（點開檔案）匯入 |

- 看得懂的日期：今天、明天、後天、大後天、今晚、明早、週五／星期五／禮拜五、這週五、下週一、下下週三、3天後、2週後、
  11/12、11月12日、2026-11-12、15號。時間：14:00、14:00-15:30、下午2點、下午兩點半、晚上8點15分、9am、中午。
- 沒寫年的日期今年已經過了就算明年；「15號」過了算下個月；沒寫結束時間預設一小時；沒寫時間＝整天。
- **提醒**：SYNOX 還沒有給 pack 用的排程 API，所以這個 pack 不會自己響。加有時間的行程時會附一行
  `/remind_add 13:30 看牙醫 date=2026-11-10`，要提醒就照打。
- 網頁介面的工具頁有「今天＋7 天」面板（`GET /api/packs/calendar/today`）。

資料：`data/calendar.json.enc`（保管箱加密；伺服器版每人一份 `data/users/<id>/calendar.json.enc`）。
`/cal_ics` 會在你自己的資料夾（個人版 `data/calendar/files/`、伺服器版 `data/users/<id>/calendar/files/`）暫時寫一個 .ics、
送出後馬上刪掉，所以 `pack.json` 宣告了 `filesystem:own`（這是工具庫裡唯一需要宣告的能力）。不連網、不開別的程式。
（0.1.1 起；0.1.0 寫在全部人共用的 `data/packs/calendar/`，SYNOX 的資料歸屬檢查不讓 `data: user` 的工具這樣用。）
檔名每次不一樣（`export-<時間>-<亂數>.ics`，0.1.2 起）：同時匯出兩次不會互相蓋掉；萬一程式在送出前被關掉而留下檔案，
下次匯出時會先清掉（10 分鐘以前的）。
