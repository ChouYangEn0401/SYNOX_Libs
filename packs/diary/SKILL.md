# 日記（diary）

一篇日記＝**某一天**＋**一個題組**（一組問題）的答案。同一天可以有好幾篇，一個題組一篇；同一天同一個題組再寫一次＝更新那一篇。
每個工具回一段給人看的字（寫進哪一篇、填了幾題、哪幾題沒動）；錯誤是 `❌` 開頭的一句人話，直接轉述給使用者就好。

## 工具一覽

| 工具 | 做什麼 | 什麼時候用 |
|---|---|---|
| `diary__jot` | 把一句話（`text`，作者原話）記成**今天**「隨手記」的新的一則；接在之前那幾則後面，不蓋掉 | 使用者說「記一下：…」「幫我記：…」、只是想留一句話，沒要格式、沒要整理 |
| `diary__templates` | 全部題組：名稱、什麼時候用、幾分鐘、分類（`structure`／`reflection`／`flow`）；可以篩 | 要挑題組、使用者問有哪些格式 |
| `diary__template` | 一個題組的每一題：id、題型、選項、填空格數 | **填之前一定先看** |
| `diary__suggest` | 替一段文字排出最像的幾個題組，每一個附「為什麼」 | 使用者說「你幫我挑」。把理由用一句話講給他、讓他選，不要自己決定 |
| `diary__categories` | 分類：每一種結構、反思層級、步驟、分組、標籤各有哪些題組 | 使用者想「照分類挑」（先問要不要信仰的、要幾段的） |
| `diary__show` | 某一天的每一篇（純文字）；`date` 給編號＝看那一篇 | 使用者要看某天；整理之前先看那天寫了什麼 |
| `diary__list` | 最近寫過的日記：日期、題組、字數、編號 | 「我最近寫了哪幾天」 |
| `diary__put` | 把**作者自己的話**寫進某一天、某個題組，**只填空著的題目**。`answers` 給 JSON；給一段純文字＝整段寫進那個題組的第一個文字題（`jot`＝新的一則） | 使用者交代了要填什麼；別天的隨手記（`date`＝那天、`template`＝`jot`、`answers`＝他的話） |
| `diary__put_ai` | 把**你整理過的版本**寫進去：每一題標「AI 整理」、附作者原文；作者已經寫過的題目不動 | 使用者說「幫我潤飾」「幫我整理成日記」 |
| `diary__overwrite` | 換掉**點名的**幾題（`fields`＝題目 id，逗號分開）。會送確認卡 | 使用者要改某一兩題（補經文原文、改錯字） |
| `diary__export` | 做成一頁 HTML ＋ 一張卡片 SVG，直接傳給使用者 | 「做成圖」「給我一頁」；改完內容再叫一次就是新的 |
| `diary__image_prompt` | 從那一篇做一段畫圖用的 prompt（中英各一段，照原文） | 「幫我把今天畫出來」 |
| `diary__title`、`diary__switch` | 替一篇取標題；替一篇換題組（答案一個都不刪） | 使用者說「這篇叫…」「改用三行日記的格式」 |
| `diary__rm`、`diary__trash`、`diary__undelete` | 刪一篇（進垃圾桶，會送確認卡）、看垃圾桶、救回來 | 使用者說要刪、或刪錯了 |
| `diary__history`、`diary__restore` | 一篇的歷史版本、放回某個版本 | 「剛剛那篇被我改壞了」 |
| `diary__backups`、`diary__backup` | 整本的備份與狀態、現在備份一份 | 使用者問備份 |
| `diary__settings`／`diary__settings_set` | 看、改設定（預設題組、版型、幾點換日 `day_start_hour`…） | 使用者說「以後都用三行日記」「我都半夜寫，兩點以前算前一天」 |
| `diary__setup`、`diary__setup_init`、`diary__tpl_restore` | 狀態與還沒拿出來的內建題組、挑起始組合（generic＝不談信仰）、把一個內建題組拿出來 | 使用者第一次用、或想要某個沒出現的題組 |

`date` 收 `YYYY-MM-DD`、`today`、`yesterday`（照設定 `day_start_hour` 換日）；「上週五」自己換成日期。
整本匯出、匯入（`/diary_export_all`、`/diary_import`）只給使用者本人在 Telegram 或網頁上打，不是你的工具。

## 情境

**「記一下：今天很好」（只是要留一句話）**：`diary__jot`（`text`＝他的話，一字不改；不要先問格式、不要潤飾）。
別天的就 `diary__put`（`date`、`template`＝`jot`、`answers`＝他的話）。回一句「記好了」就好。

**「幫我記一下／幫我整理成日記」（使用者把話打出來了）**

1. `diary__suggest`（`text`＝他的話）→ 把前兩三個題組跟理由用一句話講給他、讓他選；他指定了就用指定的。對不上名稱就 `diary__templates` 找兩三個最像的給他選，不要猜。
2. `diary__template`（看每一題的題型、選項、填空格數、每一題怎麼填）。
3. 要**原文照存**：`diary__put`，answers 用他的字。要**潤飾**：`diary__put_ai`，JSON 一定要有 `source_text`（他的原話，一字不改）；每一題各自對應的原文放 `sources`。
4. `diary__export`（同一個 `date`、`template`）→ 檔案會直接傳給他。
5. 回覆只說做好了哪一篇、填了幾題、哪幾題標了 AI 整理；**不要把日記整段貼回去**。

**「把某一題改一下」（例：經文只寫了出處，要補原文）**

1. `diary__show` 看那一篇（找出題目 id；`diary__template` 也看得到）。
2. `diary__overwrite`：`fields`＝那一兩題的 id、`author`＝`user`（他說的話）或 `ai`（你整理的，JSON 附 `source_text`）。**不要用 `all`**，除非他明說整篇重寫。
3. `diary__export` 重新產出。

**「我某天寫了什麼」**：`diary__show`。輸出只有你看得到——他要全文就給全文，要重點就整理重點；只給他問的那一天。

**「有哪些格式／幫我分類」**：`diary__categories` → 先問他要哪一種（不談信仰的／有禱告的；一段式／三段式），再列那一類的題組。

## 分類：每個題組是哪一種寫法

| 欄位 | 值 |
|---|---|
| `structure` | `one-part` 一段式／`three-part` 三段式／`n-part` 多段式 |
| `reflection` | `none` 只記錄 → `reflection` 有反思（不談信仰）→ `devotional` 有信仰的反思 → `prayer` 有禱告／代禱（階梯，後面的包含前面的）。不談信仰 → `reflection=none,reflection` |
| `flow` | 步驟的順序：`events` 發生的事、`feelings` 感受、`scripture` 經文、`reflection` 反思、`prayer` 禱告、`gratitude` 感恩、`worries`、`work`、`decision`、`review`、`identity`、`checkin`、`confession`、`trust`、`people`、`quote`、`plan` |

## 挑哪一個

1. **作者指定了就用指定的**（名稱、id、或「三行那個」這種說法都算；對不上就列兩三個最像的給作者選，不要猜）。
2. 沒指定：先看那天寫了什麼，**照內容的形狀挑**，不是照你覺得作者該寫什麼：

| 那天寫的是 | 先考慮 |
|---|---|
| 很短、零碎、只有幾句 | `three-lines`（一件事一個感覺一件謝謝）、`free-bullets`（一則一則＋感恩代禱） |
| 一直在擔心、停不下來 | `worry-sort` |
| 很難過、很受傷、事情很糟 | `hard-day`（不談信仰也可以）；作者在向神哭訴、有詩篇那種語氣 → `lament` |
| 說不出是什麼心情 | `feelings` |
| 有一件事想想到底、有學到東西 | `capsule`（一件事一塊，最多三件）；不談信仰、想分三段看 → `day-review` |
| 同一天有很開心和很難受的事 | `peaks-valleys` |
| 讀經、禱告、靈修的內容 | 有經文和應用 → `three-part`；很忙只想打卡 → `quick-checkin`；睡前回看 → `examen`；想填空 → `scripture-fill` |
| 在想自己要成為怎樣的人 | `become` |
| 工作、專案、創業 | `founder-daily`；在做一個重要決定 → `decision-log` |
| 一整週或一整個月的回顧 | `week-review`、`month-review` |
| 都不太像 | 保持 `jot`（原文照存，不套範本），或問作者 |

3. 寫的東西跟題組的題目對不太上是可以的——**空的題目輸出時不會出現**，不要為了填滿而編內容。

## 每一種題型怎麼填（`answers`）

| 題型 | 給什麼 | 例 |
|---|---|---|
| `text` | 一段字（純文字，換行會保留） | `"今天跟同事吵了一架…"` |
| `short_text` | 一句話 | `"準時下班"` |
| `list` | 字串陣列，一項一個（也可以給一段字，一行一項） | `["家人平安", "雨停了"]` |
| `choice`／`scale` | **一個選項**的 id 或文字（要完全對得上選項） | `"yes"` 或 `"有"` |
| `multi_choice` | 選項 id 或文字的陣列 | `["焦慮", "疲累"]` |
| `fill` | 字串陣列，**格數＝填空格數**，照順序 | `["腓立比書 4:6", "應當一無掛慮"]` |

對不上選項的、不是這個題組的題目會被略過，回覆會寫幾題略過。一個欄位最多 2000 字：很長的一篇分幾次 `diary__put`（每次給幾題，只填空著的）。

## 填寫的原則

- **用作者自己的話。** 可以整理、拿掉贅字，不要改寫成你的句子，**不要加作者沒寫的情節、感受、結論**。
- **AI 整理的版本一定走 `diary__put_ai`**，不要用 `diary__put` 假裝是作者寫的；`source_text` 永遠是他的原話。
- **不替作者下結論、不替作者認罪、不替作者打分數。** 「學到什麼」「主在哪裡」這種題目，作者沒說就留空。
- **沒提到的就留空。** 空的題目輸出時不會出現，不是失敗。勾選題只能用那一題的選項、只照他自己說的選。
- **經文只照抄作者寫過的**，不要憑記憶補經文原文；只給出處。
- 信仰類題組（`reflection` 是 `devotional`／`prayer`）只在他提到信仰、或他自己選的時候用。
- 「事後回來寫」的題目（`decision-log` 的 `later` 那一段）當天一律留空。
- `jot` 的「從經文來的回應（AI 整理）」不是作者寫的話，不要搬到別的題組裡當成作者的答案。
- 回覆說「幾題原本就有寫、沒有動」「幾題是作者自己寫的、沒有動」＝那幾題他已經寫了：要換要用 `diary__overwrite` 並先問他。

## 隱私

日記是最私人的東西：工具的輸出不要整段複述、不要記到別的地方；回結果就好（哪一篇、幾題、檔案傳了沒）。
整理的時候只用作者給你的那一天，不要順手去讀別的日子。
