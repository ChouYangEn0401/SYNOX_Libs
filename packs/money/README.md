# 💰 money（記帳）

簡單記帳：支出、收入、轉帳分開算；類別是你自己的，可以從範本開始。設計見 [ADR-0002](../../docs/adr/0002-money-general-version.md)。

## 記帳

| 指令 | 做什麼 |
|---|---|
| `/money <金額> [類別] [備註]` | 記一筆支出，例如 `/money 120 午餐 跟同事`。類別可以不填（放「待分類」） |
| `/money_in <金額> [類別] [備註]` | 記一筆收入，例如 `/money_in 32000 薪資` |
| `/money_transfer <金額> [類別] [備註]` | 記一筆轉帳：存錢、投資、還款、繳卡費。**不算花費、不吃預算** |
| `/money_undo` | 撤銷最後記的那一筆 |
| `/money_rm <編號>` | 刪掉某一筆（編號看 `/money_list`；AI 要刪會先問你） |

三個記帳指令都可以多加：

- `date=昨天`、`date=11/8`、`date=2026-11-08`：補記別天的帳（預設今天）。
- `account=信用卡`、`account=現金`：用什麼付。只是標籤，不算餘額。

## 看帳

| 指令 | 做什麼 |
|---|---|
| `/money_list [筆數]` | 最近幾筆（預設 10）。可以篩：`keyword=咖啡`、`category=午餐`、`month=2026-10`、`kind=收入` |
| `/money_month [月份]` | 這個月（或 `2026-10`）：支出照類別分，另外列收入、轉帳；預算與上限還剩多少 |
| `/money_budget <金額>` | 每月總預算（0＝拿掉）；記一筆超過時回覆會提醒 |
| `/money_cap <類別> <金額>` | 某個支出類別每月的上限（0＝拿掉）；超過只提醒、不擋 |

## 類別

| 指令 | 做什麼 |
|---|---|
| `/money_cats [名稱]` | 列出你的類別；給名稱看那一個的種類、關鍵字、上限 |
| `/money_cat_add <名稱> [大類] keywords=… kind=…` | 新增類別；同名就是更新（改大類、種類、加關鍵字）。`kind` 是 支出／收入／轉帳 |
| `/money_cat_rm <名稱>` | 刪類別（已經記的帳不動） |
| `/money_template [名稱]` | 不給名稱＝列出範本；給名稱＝載入 |

- **一開始一個類別都沒有**，類別直接打字也記得下。想省事就載範本，之後自己改、刪、加。
- **關鍵字猜類別**：打的字不是你的類別名、但含某個類別的關鍵字（或名稱），就記到那個類別，原本打的字留在備註
  （例如有「飲料」類別、關鍵字有「拿鐵」，`/money 65 拿鐵` 就記成飲料）。最長的關鍵字優先；猜錯就 `/money_undo` 重記。
- 類別的**種類**決定這筆算什麼：記到「存錢」這種轉帳類別，用 `/money` 也是轉帳，不算花費。

### 範本（選配，下指令才載入；載兩次不會重複，也不會蓋掉你改過的）

| 範本 | 內容 |
|---|---|
| `基本`（basic） | 早餐、午餐、晚餐、點心宵夜、飲料、衣著、居家、交通、學習、娛樂、醫療、其他 |
| `帳單`（bills） | 房租、水電瓦斯、管理費、手機網路、訂閱 |
| `存錢與投資`（saving） | 存錢、投資、還款、繳卡費（這四個是轉帳，不算花費）、利息 |
| `捐贈`（giving） | 捐款、十一奉獻 |
| `收入`（income） | 薪資、兼職、退款回饋、其他收入 |

關鍵字只放通用詞（沒有店名、品牌）；想更準就自己加：`/money_cat_add 飲料 keywords=冰沙,豆漿`。

**信用卡**：刷卡就記那樣東西（例如 `/money 1200 晚餐 account=信用卡`），繳卡費時記 `/money_transfer 1200 繳卡費`
（或載了「存錢與投資」範本後 `/money 1200 卡費`）。繳卡費是轉帳，所以同一筆錢不會算兩次。

## 資料

- 保管箱加密：個人版 `data/money.json.enc`；伺服器版每人一份 `data/users/<id>/money.json.enc`。
  帳、類別、關鍵字、付款方式都只在你自己那一份。
- 資料格式第 2 版（`"schema": 2`）。從 0.1.x 升上來：舊的帳自動補編號、日期、種類（都算支出），不用做什麼。
- **退回 0.1.1**：資料不會壞，但 0.1.1 不認得收入與轉帳，會把它們都當成花費算進「這個月」。
