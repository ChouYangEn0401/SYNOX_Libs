# 💰 money（記帳）0.5.0-alpha.1

> **alpha（尚未實機驗證）**：0.4.0 是整個重做的版本，0.5.0 補上對帳單匯入與「寫檢討的 AI」接頭；都只在自動測試（假資料）裡跑過，
> 還沒在真的 SYNOX／Telegram 上試過。實機試過、沒問題之後才會發沒有 `-alpha` 的版本。

記支出、收入、轉帳；每期收入怎麼分、各格預算、信用卡與分期、週月檢討；附一個完整的記帳畫面。
帳本是你自己資料夾裡的一個 SQLite 檔，**沒有加密**（見「資料」）。設計見 [ADR-0004](../../docs/adr/0004-money-remake.md)。

## 記帳（聊天指令）

| 指令 | 做什麼 |
|---|---|
| `/money <金額> [類別] [說明]` | 記一筆支出，例如 `/money 120 午餐 範例便當店`。類別可以不填：先看關鍵字，吃的依時間分餐，猜不到放待分類 |
| `/money_in <金額> [類別] [說明]` | 記一筆收入，例如 `/money_in 32000 薪資` |
| `/money_transfer <金額> …  to=<帳戶>` | 轉帳：存錢、繳卡費、還款、轉到別的帳戶。**不算花費** |
| `/money_iou <金額> …  direction=lend／owe／collect／repay` | 代墊與欠款：幫別人先付、別人幫我付、收回、還錢 |
| `/money_edit <編號> [amount=] [desc=] [category=] [date=] …` | 改一筆（只改有給的；`-` 清掉） |
| `/money_rm <編號>` | 刪一筆（會先問；可以整批復原） |
| `/money_undo`、`/money_revert <批次>` | 撤銷最近一次寫入、撤銷指定的那一批 |
| `/money_list`、`/money_show <編號>` | 最近幾筆（可以照期別、日期、類別、帳戶、關鍵字篩）、看一筆的完整內容 |
| `/money_note <日期> <內容>` | 這一天的小日記 |

- 日期：`date=今天／昨天／前天／1/15／2030-01-15`（預設今天；只寫月日的算今年；不能記明天以後）。
- 金額：照帳本的幣別。新台幣是整數；小數位數 2 的幣別可以打 `99.5`。千分位逗號、「元」都可以。
- 一批混合紀錄（給 AI 用）：`/money_ingest records=<JSON>`；同一批重送不會多記。

## 看帳與預算

| 指令 | 做什麼 |
|---|---|
| `/money_summary` | 本期還能花多少、每天可花、各大類、要注意的事 |
| `/money_check` | 額度提醒：超支、花太快、到期沒做的固定項目 |
| `/money_envelope` | 錢怎麼分的每一格：計畫多少、做到多少、還剩多少 |

| `/money_month`、`/money_budget`、`/money_cap`、`/money_cats`、`/money_cat_rm`、`/money_template` | 0.3.x 的舊指令，照樣能用 |

## 只在聊天用的進階功能

信用卡（`/money_card`、`card_statement`、`card_match`、`card_pay`）、負債與分期（`/money_debt`）、

## 完整畫面（記帳本）

六個分頁：

| 分頁 | 內容 |
|---|---|
| 🏠 總覽 | 本期還能花多少、每天可花、日曆、錢怎麼分的每一格（跳過、撥額度、挪用）、待解決的事、今年 |
| 📒 明細 | 像存摺一樣一筆一行（右邊是那筆之後的餘額）；最上面一行就能記一筆；點一筆可以改或刪 |
| 🐷 撲滿 | 投資與資金操盤（見下面「撲滿」）。沒有證券帳戶、也沒開投資選配時不顯示 |
| 💬 檢討 | 週與月的檢討書：看、回覆、按「照這個分」改下一期的分配 |
| 📋 規劃 | 每期收入怎麼分、各格與各大類的金額、固定項目 |
| ⚙️ 設定 | 類別（用途 → 大類 → 細項）、帳戶、帳本設定（幣別、每期起算日、時差、提醒日）、選配功能、帳本 |

- **第一次用**：還沒記過帳的新帳本會先跑三步驟引導（幣別與每期起算日 → 起始類別與選配功能 → 每期大概收入與生活費，可跳過）。
  已經在聊天記過帳、或是從 0.3.x 升級過來的帳本不會跑引導。
- **怎麼開**：SYNOX 網頁的工具頁 → 記帳 →「完整畫面」卡片按「開啟」，再按「打開」。
  畫面上做的每件事跟打指令是同一份邏輯、同一份檢查；聊天裡記的，回到畫面就會更新。
- 刪一筆、撤銷一整批、開新帳本是危險動作，SYNOX 會先跳確認框。手機入口可以看、可以記，危險動作與匯出要回電腦做。

## 撲滿

- 記交易明細（買、賣、股利、費用）、開倉收倉、移動平均成本、跟「基準」比較、對實際股數。
- **沒有證券帳戶、也沒開「投資」或「資金操盤」選配時，看不到這個分頁。**
- 交易可以在撲滿分頁一筆一筆記（或打 `/money_trade_add`），也可以**匯入對帳單**（見下一節）。股價用 `/money_price_push` 自己塞，工具不會上網抓。
- 基準的代號與名字**預設空白**，到撲滿的設定自己填（沒填就叫「基準」）；比較用的年率預設兩成、保守線一成，都可以改。
- 「捐贈」比例與打勾只在開了「捐贈」選配時出現。
- 目前只支援**整數幣別**（小數位數 0，例如新台幣）：小數位數不是 0 的帳本不會出現撲滿分頁。

## 對帳單匯入（0.5.0）

- 把對帳單放進自己的檔案資料夾（網頁另存成 `.html`，或 CSV），打 `/money_import_statement <檔名>`；先加 `dry_run=yes` 試算看看。
- 能讀三種：**成交明細**（買、賣、當沖每一腳）、**期貨選擇權日報表**、**已實現損益**（拿來核對賣出、補記當沖）。
  照對帳單寫的數字記；帳本已經有的不重記；每天的小計、當沖、每個契約的損益都核對，對不上的列出來（不自己改帳本）；同一份重匯不會多記。
- 選項：`format=`（不給＝照表頭自己認，剛好一種對得上才用）、`account=`（證券帳戶；投資那一層只有一個就不用給）、
  `book=`（期貨選擇權一定要；成交明細與已實現損益的當沖記進這一倉）、`close=yes`（期貨都平倉了就收倉）。
- **格式不寫在程式裡**：每一種對帳單長什麼樣子寫在「格式描述檔」（JSON）。`/money_formats` 列出能用的。
  內建幾份範例（台灣券商網頁對帳單常見的欄位、一份通用的 CSV 交易清單）；你的對帳單欄位不一樣，就複製一份內建的，
  改 `id` 與欄位名，放進自己檔案資料夾的 `formats/`（同一個 `id` 會用你的）。描述檔有錯時 `/money_formats` 會列出每一個問題。
  怎麼寫見 `engine/services/statements/` 每個檔開頭的說明與 `engine/formats/` 的範例。
- 選擇權放到到期會記成 0 元歸零：價內到期有拿到錢要自己補（匯入的回覆會列出來）。

## 寫檢討的 AI（0.5.0）

- 平常的路不變：SYNOX 的 AI 助理讀 `/money_report review=yes` 的數字與規則、寫好用 `/money_review_save` 存回來。
- `/money_review_run`：請「接上的 AI」直接寫。這個工具不綁任何 AI、不叫任何外部程式；**SYNOX 現在還沒有給工具用的 AI 入口，
  所以預設沒有接上**，打了會說「還沒有接上」，什麼都不寫，其他功能照常。

## 資料

- 帳本在你自己的資料夾：個人版 `data/money/files/book/`，伺服器版每人一份 `data/users/<編號>/money/files/book/`。
  裡面有帳本檔、每日備份（`backups/`，留最近 14 天）、換帳本時的封存（`archive/`）、收據（`attachments/`）。
- **都沒有加密**：帳本、備份、封存、匯出的 CSV 都是一般的檔案。誰能讀那個資料夾，就讀得到你的帳。
  （SYNOX 的保管箱只用來放 0.3.x 的舊資料。）
- **備份**：每天第一次寫入前自動備份一份。要自己另外備份，複製整個 `book/` 資料夾就好（SYNOX 沒在跑的時候複製最穩）。
- **匯出**：畫面的設定頁可以下載整本帳（CSV：每一列是「表名＋那一列的內容」）與照篩選的帳目 CSV；
  個人版下載前會提醒沒有加密，伺服器版不給匯出。
- 多人共用的 SYNOX：每個人一本帳、一把寫入鎖，彼此看不到；畫面與指令都沒有「選哪個使用者」的欄位。
  但帳本沒有加密，伺服器的管理者（能讀 SYNOX 資料夾的人）讀得到每個人的帳。個人版改成伺服器版時，舊資料不會自己搬（[ADR-0006](../../docs/adr/0006-personal-and-server-mode.md)）。

## 從 0.3.x 升級

- 什麼都不用做：第一次用新版時，舊的帳（每筆、類別、關鍵字、每月預算、單類上限、付款方式）自動轉進新帳本，整段是一批寫入，
  可以用 `/money_undo` 整批撤銷。付款方式變成帳戶；舊資料有小數的話，帳本改成 2 位小數。
- 舊資料不刪：另外存一份在 SYNOX 保管箱裡（工具的存放區，鍵名 `legacy-0.3`）。
- 舊指令都還在（`/money`、`/money_in`、`/money_transfer`、`/money_list`、`/money_month`、`/money_budget`、`/money_cap`、
  `/money_cats`、`/money_cat_add`、`/money_cat_rm`、`/money_template`、`/money_undo`、`/money_rm`、`/money_edit`），工具頁的小面板也照舊。
- **不能自動退回 0.3.x**：新記的帳在新帳本（SQLite）裡，0.3.x 讀不到。退回舊版看到的是升級前那一份舊資料。

## 需要什麼

- SYNOX 要支援「多檔工具」（`pack.json` 的 `python.package`）；舊的 SYNOX 載不起來。
- 宣告的能力：`filesystem:own`（只讀寫你自己的資料夾）。不連網、不開別的程式。
