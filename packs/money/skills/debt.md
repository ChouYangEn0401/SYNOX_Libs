# 分期、負債、信用卡帳單

## 分期買東西（刷卡分期）

用 `money__ingest` 送一筆 installment_purchase：帳本會記一筆支出（標成分期，不算進當期的薪水分配），
再建一份每期的排程；之後信用卡帳單上的每一期會自動對到排程。

| 欄位 | 怎麼填 |
|---|---|
| name | 買了什麼（例：手機）；必填 |
| card | 刷哪張卡；必填 |
| total | 總價；必填 |
| periods | 分幾期（2–60）；必填 |
| date | 購買日 YYYY-MM-DD；必填 |
| per_period | 每期金額；不填＝總價÷期數，除不盡的零頭放在**第一期** |
| first_due | 第一期出現在帳單上的日期；不填＝購買日 |
| category | 細項（大額採買、進修…）；不填會猜 |
| nature | positive 進修或投資自己、negative 消費（預設）、wear 生活必要 |

「手機 20000 刷範例卡分 12 期」：

```json
{"records": [{"type": "installment_purchase", "name": "手機", "card": "範例卡", "total": 20000, "periods": 12, "date": "2030-01-10"}]}
```

每期 1,666，第一期 1,674（零頭 8 放第一期）。

## 信用卡帳單

使用者丟來帳單（截圖或文字）：照帳單一列一列寫成 card_statement，用 `money__ingest` 送。帳本會跟記帳逐列對：

| 結果 | 意思 |
|---|---|
| 對上 | 金額一樣、日期接近 |
| 金額不同 | 對到了，但金額差一點 |
| 漏記 | 帳單上有、帳裡沒有 |
| 分期 | 分期的某一期 |
| 手續費 | 年費、利息、手續費（通常還沒記） |

```json
{"records": [{"type": "card_statement", "card": "範例卡", "closing_date": "2030-01-10", "due_date": "2030-01-25", "total": 490,
  "lines": [
    {"date": "2029-12-12", "desc": "範例便當店", "amount": 120},
    {"date": "2029-12-20", "desc": "範例書店", "amount": 250},
    {"date": "2030-01-05", "desc": "年費", "amount": 120}
  ]}]}
```

- 退款、繳款那一列的金額寫**負的**。
- 分期那一列照帳單寫（例「分期 手機 3/12期」），帳本會自己認。
- 同一張帳單重送不會變兩張；內容不同就更新。
- 帳單很長，一次放不下（每次 2000 字內）：請使用者打 `/money_card_statement`，
  逐列用分號分開放在 lines、lines2…lines5（例 `lines=12/12 範例便當店 120; 12/20 範例書店 250`）。

工具回的提醒（漏記幾筆、金額不同、手續費還沒記）照實告訴使用者。接下來的處理是人做的：
- 看每一列：`/money_card statement=<帳單編號>`
- 補記、改成帳單金額、改到這張卡、不用管：`/money_card_match <列編號> action=補記`
- 手動對到某一筆：`/money_card_match <列編號> <帳的編號>`
- 繳費：`/money_card_pay <帳單編號>`（記成轉帳，不算支出）

## 其他負債（自借款、信貸）

建立、看排程、還一期都是人打的指令：
- `/money_debt`：列出（每月固定要還多少、每筆還剩多少）
- `/money_debt add name=範例信貸 kind=信貸 periods=24 principal=120000 start=2030-02-01 account=範例信貸帳戶`
- `/money_debt pay <編號>`：還一期（自借款、信貸會記一筆轉帳；卡分期只標成已付，錢在帳單裡）

使用者在聊天裡說「這個月的信貸繳了」：可以直接 `money__transfer`（purpose=debt）記那筆轉帳，
再提醒他打 `/money_debt pay <編號>` 把那一期標成已付。

## 注意

- 分期的支出**只記一次**（買的那天、總價）；每期的扣款不要再記成支出。
- 卡費是轉帳（transfer.md），不是支出。
