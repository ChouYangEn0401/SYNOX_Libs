# 🗂️ workspace（工作區）

> **0.1.0-alpha.1：alpha（尚未實機驗證）**——只在這個 repo 的自動測試裡跑過，還沒在真的 SYNOX／Telegram 上試過。

讓 SYNOX 看你電腦上**一個指定的資料夾**（工作區）、讀裡面的文字檔、用內建範本建新專案。
它只有一份**寫死的菜單**：沒有「執行這句話」、沒有「跑這個指令」，所以不管誰（包括被網頁或檔案騙了的 AI）怎麼下指令，
都繞不出這份菜單、也碰不到工作區以外的地方。設計與理由見 [ADR-0009](../../docs/adr/0009-workspace-tool.md)。

## 第一次用：設定工作區

工作區要你**本人**設定（AI 不能設）：

| 你打 | 結果 |
|---|---|
| `/ws_root default` | 在「文件」裡建一個空的 `SYNOX_Workspace` 資料夾，當成工作區（建議） |
| `/ws_root D:\Projects\SYNOX_Workspace` | 用你指定的資料夾（要已經存在） |

設定時會檢查，下面這些都不能當工作區：磁碟的最上層（`C:\`）、你的家目錄或包含家目錄的資料夾、系統或程式資料夾、
別人的家目錄、`AppData` 或 `.ssh` 這類禁區裡面、裡面直接放著 `.ssh`、`.git`、金鑰、`.env` 的資料夾。
建議用一個**專門放新專案的空資料夾**。「文件」被 OneDrive 搬走、`default` 找不到的話，改用完整路徑。

## 菜單（全部）

| 指令 | 做什麼 | 誰能叫 |
|---|---|---|
| `/ws [資料夾]` | 列出資料夾裡有什麼（不寫＝最上層；最多 200 個） | 你、AI |
| `/ws_read <檔案> [line=行號]` | 讀文字檔（一次最多 120 行、3000 字；只讀前 256 KB）。二進位檔只說大小與類型 | 你、AI |
| `/ws_tree [資料夾] [depth=1～4]` | 樹狀圖（預設兩層，最多 150 行） | 你、AI |
| `/ws_find <名字的一部分> [under=資料夾]` | 用名字找檔案或資料夾（不分大小寫；最多 50 個） | 你、AI |
| `/ws_templates` | 有哪些內建範本、各會建哪些檔 | 你、AI |
| `/ws_status` | 工作區設在哪、最近 10 筆改動 | 你、AI（AI 只看得到資料夾名字，看不到完整路徑） |
| `/ws_new <範本> <名字>` | 用範本建新專案：**先送一張卡列出完整的檔案清單**，10 分鐘內按「建立」才建 | 只有你 |
| `/ws_mkdir <資料夾>` | 建一個新資料夾（一次一層） | 只有你 |
| `/ws_root <完整路徑或 default>` | 設定工作區 | 只有你 |

路徑一律寫**工作區裡的相對路徑**，用 `/` 分開，例如 `my-app/src/app.py`。專案名只能用小寫英文、數字和 `-`。

### 內建範本

| 範本 | 會建的檔 |
|---|---|
| `empty` | `README.md` |
| `python-cli` | `README.md`、`.gitignore`、`pyproject.toml`、`src/<名字>/__init__.py`、`__main__.py`、`cli.py`、`tests/test_cli.py` |

建好的專案要怎麼跑寫在它的 README 裡；那些指令要你自己在終端機打，**SYNOX 不會替你執行**。

## 不能做的事（故意的）

- **不執行任何程式或指令**：沒有 git、沒有 pytest、沒有 pip。這個工具寫出的檔它自己永遠不會執行。
- **不刪、不改、不覆蓋**：只會建新的資料夾和新的檔案；那裡已經有東西就不建。
- **不碰工作區以外**：絕對路徑、`..`、磁碟機代號、網路路徑（`\\server`）、`%2e`、`~`、全形的 `／．`、`CON`／`NUL` 這種保留名稱、
  結尾是空白或點的名字、以 `-` 開頭的名字，一律拒絕。
- **不跟進連結**：路上經過捷徑（symlink）或資料夾連結（junction）一律拒絕；有別的名字的檔（硬連結）不讀。
- **禁區**：就算在工作區裡也不碰——`.git`（含 hooks）、`.ssh`、`.gnupg`、`_keys`、`.env*`、`*.pem`、`*.key`、`id_rsa*`、
  名字含 secret／password／credential 的檔、`AppData`、瀏覽器的使用者資料（`User Data`、`Chrome`、`Edge`、`Firefox`、`Mozilla`…）。
  名字剛好叫 `chrome`、`edge` 的專案資料夾也會被當成禁區，請換個名字。
- **不建可執行的檔名**：`.bat`、`.cmd`、`.ps1`、`.exe`、`.vbs`、`.js` 等。
- 不連網、不開埠、不讀環境變數。

## 資料存哪

- 工作區的位置、等你確認的那張建專案卡、最近 100 筆改動紀錄：加密存在 SYNOX 的保管箱（`pack.store`，每個人一份）。
- 改動紀錄只有「時間、動作、目標的相對路徑、成功與否」，**不記檔案內容**。
- 安裝報告會把這個工具標成「讀寫 pack 以外的檔案」（`filesystem:any`）——它真的要讀你的工作區，這是對的，請看清楚再按同意。
  只給擁有者用（`access: owner`），伺服器版的成員看不到。

## 已知的限制

- 檢查和實際動作之間有一瞬間的空檔：如果**別的程式**剛好在那一刻把工作區裡的資料夾換成連結，理論上可能讓建立的動作跟著連結走。
  這個工具自己不能建連結；建完之後會再檢查一次，發現不對就報錯。v1 之後要靠 SYNOX 的沙盒補上這一層（ADR-0009 第 6 節）。
- 只認 UTF-8 的文字檔；Big5 之類的編碼會被當成「不是文字檔」。
