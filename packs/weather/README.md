# 🌤️ 天氣與穿衣

讓 SYNOX 告訴你現在天氣、未來幾天預報、今天穿什麼要帶什麼、空氣品質與紫外線，還有颱風假（各縣市停班停課）。
**不用申請任何金鑰**：天氣用 Open-Meteo 的免費 API，停班停課看行政院人事行政總處的公開網頁。

> 這是 **SYNOX 工具庫（SYNOX_Libs）** 的工具，**🧪 alpha（尚未實機驗證）**：只用假資料測過，還沒在真的 SYNOX／Telegram 上長時間用過；
> 穿衣規則是自己寫的、停班停課是讀網頁（網頁改版就可能看不懂），功能都有，但還不完善。
> 先把 `weather-<版本>.synoxpack` 裝進 SYNOX（裝法見工具庫的 [README](../../README.md)「給使用者：怎麼裝」）。

## 快速開始

```
/wx_set 地點 台北      先設預設地點（之後不用每次寫）
/wx                    現在天氣＋未來 3 天
/wx_wear 上班          今天上班穿什麼、帶什麼
/wx_typhoon 台北       台北有沒有停班停課
```

## 指令

| 指令 | 做什麼 |
|---|---|
| `/wx [地點] [天數]` | 現在天氣（溫度、體感、濕度、風、UV）＋未來幾天預報（高低溫、降雨機率、UV），附一行穿衣提示。例：`/wx 高雄 5` |
| `/wx_wear [活動] [地點]` | 穿衣建議：穿什麼、要帶什麼（傘、防曬、外套…）、提醒。活動：`一般`、`上班`、`戶外`、`運動`、`旅遊`。例：`/wx_wear 運動 台中` |
| `/wx_air [地點]` | 空氣品質（AQI、PM2.5、PM10）與紫外線（現在、今天最高），附建議 |
| `/wx_typhoon [縣市]` | 颱風假：各縣市停班停課（人事行政總處公告）。不寫＝設定的縣市（沒設就列全部）；寫 `全部` 看全部 |
| `/wx_settings` | 看目前設定 |
| `/wx_set <鍵> <值>` | 改一項設定（下表）；值寫 `清除` 回到預設 |

地點可以寫：縣市名（`台北`、`臺北市`、`新北`、`花蓮`，台／臺都可以）、地名（`Taipei`、`Hualien`、中文地名也可以試）、或座標（`25.03,121.56`）。

## 設定（`/wx_settings` 看、`/wx_set` 改）

| 鍵 | 值 | 預設 | 用在哪 |
|---|---|---|---|
| `地點` | 縣市、地名或座標 | 沒有（不寫地點時會問你） | `/wx`、`/wx_wear`、`/wx_air` 沒寫地點時 |
| `體感` | `怕冷`／`普通`／`怕熱` | `普通` | 穿衣建議的溫度門檻：怕冷當成冷 3 度、怕熱當成熱 3 度 |
| `活動` | `一般`／`上班`／`戶外`／`運動`／`旅遊` | `一般` | `/wx_wear` 沒寫活動時 |
| `縣市` | 22 縣市其中一個 | 沒有（列全部） | `/wx_typhoon` 沒寫縣市時 |
| `天數` | 1～16 | 3 | `/wx` 預報幾天 |

SYNOX 網頁的工具頁有一小格面板，顯示目前設定（面板只能看；改設定請用 `/wx_set`）。

## 穿衣建議怎麼算（自己寫的規則）

- **穿多少**：看「現在體感」與「今天最高體感」的平均（再依 `體感` 設定加減 3 度）：30 度以上短袖透氣、26 短袖薄長褲、22 短袖或薄長袖、
  18 長袖＋薄外套、14 毛衣＋夾克、10 厚外套＋圍巾、更冷就羽絨大衣＋手套毛帽。
- **日夜溫差** 8 度以上：洋蔥式穿法、帶外套。
- **降雨**：機率 60% 以上（或今天雨量 5mm 以上、現在正在下）帶傘、穿不怕濕的鞋；30% 以上帶折疊傘。
- **風**：陣風 50 km/h 以上提醒大傘會開花、改穿防風防水外套；平均風 30 km/h 以上提醒體感更涼。
- **UV**：8 以上（過量）防曬乳＋帽子＋太陽眼鏡、10～14 點少曬；6 以上防曬＋帽子；戶外活動 3 以上就提醒防曬。
- **活動**：上班（冷氣房帶薄外套、好走的鞋）、戶外（水、防蚊液、多一層）、運動（排汗衣、替換衣服、太熱避開中午）、旅遊（好走的鞋、輕便雨衣）。

## 資料從哪來、存在哪

- **會連到的只有**：`api.open-meteo.com`（天氣）、`geocoding-api.open-meteo.com`（地名轉經緯度）、`air-quality-api.open-meteo.com`（空氣品質）、
  `www.dgpa.gov.tw`（停班停課頁）。只讀，不送你的任何資料出去（只送要查的經緯度或地名）。只用 `requests`、不開埠。
- 設定存在 SYNOX 的保管箱（密文）：個人版 `data/weather.json.enc`；伺服器版每人一份在 `data/users/<id>/`。
- 只給擁有者（`access: owner`）：伺服器版的成員、訪客看不到這個工具（要連網的工具一律這樣，[ADR-0006](../../docs/adr/0006-personal-and-server-mode.md) 第 4 節）。

## 目前不完善的地方（alpha）

- **中文地名**：Open-Meteo 的地名查詢對中文常常查不到（例如只寫「台北」「花蓮」），所以 22 縣市用內建的座標表（縣市政府附近）；
  鄉鎮、景點名可能查不到，或查到別的縣市、別國同名的地方（例如「板橋」會先找到雲林的板橋；台灣的結果優先）。查不到或不對就寫縣市、英文地名或座標。
- **預報是 Open-Meteo 的模式資料**，不是中央氣象署的官方預報；山區、離島可能差比較多。
- **空氣品質是模式估計值**（Open-Meteo Air Quality，AQI 用美國 EPA 的分級），不是環境部測站的實測值。
- **停班停課是讀人事總處網頁**：網頁改版可能看不懂，這時會告訴你並附原網址 <https://www.dgpa.gov.tw/typh/daily/nds.html>；
  各縣市的公告文字原樣列出，沒有再細分「上午／下午／某些區」。
- 穿衣規則是固定的門檻，不會學你的習慣；覺得太冷或太熱，用 `/wx_set 體感 怕冷` 或 `怕熱` 調。
- 颱風路徑、地震不在這個工具的範圍；路況是另一個工具（`road`）負責。
