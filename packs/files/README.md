# 📁 files（檔案）

> **0.1.0-alpha.1：alpha（尚未實機驗證）**——只在這個 repo 的自動測試裡跑過，還沒在真的 SYNOX／Telegram 上試過。功能是 MVP，下面「目前不完善的地方」照實列出。

讓 SYNOX（你自己打指令，或你的 AI）在**你允許的幾個資料夾**裡找檔、搜內容、讀檔、改一段字、寫新檔、搬移、刪除。
每一次改動都先備份、有編號、可以 `/fs_undo` 退回；刪除只是搬進這個工具自己的垃圾桶。不執行任何程式、不連網。
設計與理由見 [ADR-0010](../../docs/adr/0010-files-tool.md)；跟 [workspace](../workspace/README.md) 的差別：workspace 只碰一個資料夾、
固定菜單、不改既有的檔；files 可以有好幾個資料夾、可以改既有的檔，但一定可以復原。

## 第一次用：允許資料夾（只有你本人）

出廠什麼都碰不到。你本人打（AI 不能替你加）：

| 你打 | 結果 |
|---|---|
| `/fs_allow D:\Projects\demo can=write` | 允許**讀寫**這個資料夾，代號用資料夾名字（`demo`） |
| `/fs_allow D:\Docs\manuals id=manual` | 允許**只讀**，代號 `manual` |
| `/fs_unallow manual` | 拿掉（資料夾本身不動） |
| `/fs_roots` | 列出允許的資料夾（AI 只看得到代號，看不到完整路徑） |

不能加的：磁碟最上層、你的家目錄或包含家目錄的、系統與程式資料夾、別人的家目錄、`AppData`／`.ssh` 這類禁區、
SYNOX 自己與這個工具的資料夾、跟已經允許的資料夾重疊的、捷徑或 junction。最多 20 個。

## 指令

路徑寫成 `代號:相對路徑`（例 `demo:src/app.py`）；只有一個資料夾時可以省略代號；也收完整路徑（要在白名單裡）。

| 指令 | 做什麼 | 誰能叫 |
|---|---|---|
| `/fs` | 狀態：允許的資料夾、停了沒、能做什麼 | 你、AI |
| `/fs_roots` | 允許的資料夾與代號 | 你、AI（AI 看不到完整路徑） |
| `/fs_find <名字或樣式> [in=…]` | 用名字找（`report`、`*.md`、`docs/**/*.md`；新的在前） | 你、AI |
| `/fs_grep <樣式> [in=…] [glob=*.py] [fixed=yes] [case=yes]` | 搜內容（Python 正規表示式；有上限） | 你、AI |
| `/fs_read <路徑> [line=…] [lines=…]` | 分段讀文字檔；回覆有**版本號**（內容的雜湊） | 你、AI |
| `/fs_tree [路徑] [depth=…]` | 樹狀圖（不跟進連結） | 你、AI |
| `/fs_stat <路徑>` | 大小、修改時間、權限 | 你、AI |
| `/fs_write <路徑> <內容> [mkdir=yes] [dry=yes] [esc=yes]` | 寫新檔（已經有就不寫） | 你、AI |
| `/fs_write <路徑> <內容> mode=overwrite\|append version=…` | 覆寫或附加（要對得上版本號；先備份） | 你、AI |
| `/fs_edit <路徑> old=… new=… version=… [all=yes] [dry=yes]` | 把一段字換掉（`old` 要剛好出現一次；先備份） | 你、AI |
| `/fs_move <來源> <目的>` | 搬移或改名：**先送預覽卡**，按「確定」才做 | 你、AI（AI 叫的話 SYNOX 先問你，再送預覽卡） |
| `/fs_delete <路徑>` | 刪除：**先送預覽卡**；搬進垃圾桶，不是真的刪 | 同上 |
| `/fs_confirm <確認碼>` | 按鈕不能用時，用卡片上的確認碼執行 | 只有你 |
| `/fs_undo <編號>` | 退回一筆改動（每次改動的回覆都有 `#編號`） | 你、AI（AI 叫的話 SYNOX 先問你） |
| `/fs_log [筆數]` | 最近的改動紀錄（不記檔案內容） | 你、AI |
| `/fs_trash` | 垃圾桶裡有什麼、怎麼還原 | 你、AI |
| `/fs_stop [原因]` | **緊急停止**：之後什麼都不做（等確認的卡也作廢） | 誰都可以 |
| `/fs_resume` | 解除停止 | 只有你 |
| `/fs_allow`、`/fs_unallow` | 白名單（上面） | 只有你 |
| `/fs_settings` | 看設定 | 你、AI |
| `/fs_set <鍵> <值>` | 改設定 | 只有你 |

打字時空白與換行會被合併：多行內容在 `/fs_write`、`/fs_edit` 加 `esc=yes`，用 `\n` 寫換行（AI 叫的不受影響）。
內容裡不要出現 `mode=`、`version=` 這種「欄位名=」的字，會被當成欄位。單次內容最多 2000 字（SYNOX 的輸入上限）；更長的用 `mode=append` 分幾次。

## 設定（`/fs_settings` 看、`/fs_set` 改）

| 鍵 | 預設 | 範圍 | 意思 |
|---|---|---|---|
| `read_lines` | 200 | 10～2000 | read 一次最多幾行 |
| `read_chars` | 3000 | 500～3400 | read 一次最多幾個字 |
| `read_max_mb` | 20 | 1～200 | 多大的檔還讀 |
| `grep_results` | 50 | 1～500 | grep 最多回幾處 |
| `grep_files` | 5000 | 100～100000 | grep 最多看幾個檔 |
| `grep_max_kb` | 1024 | 16～20480 | grep 跳過大於幾 KB 的檔 |
| `find_results` | 100 | 1～1000 | find 最多回幾個 |
| `tree_depth` | 3 | 1～8 | tree 預設幾層 |
| `edit_max_mb` | 2 | 1～20 | write／edit 能改多大的檔 |
| `delete_max_files` | 500 | 1～5000 | 一次搬移／刪除最多幾個檔 |
| `trash_days` | 30 | 1～365 | 垃圾桶留幾天（過了就真的清掉） |
| `backup_days` | 30 | 1～365 | 改檔前的備份留幾天（過了就不能 undo） |
| `dry_run` | off | on／off | 開著時 edit／write 沒寫 `dry=` 就只預覽 |

設定只能調上限與天數；白名單、禁區、連結、版本號、備份這些安全規則**設定改不了**。

## 安全（程式強制）

- **白名單**：只碰你本人加的資料夾，每個「只讀」或「讀寫」。
- **路徑先解開再判斷**：拒絕 `..`、網路路徑（`\\server`）、裝置路徑（`\\?\`、`\\.\`）、冒號（NTFS 資料流 `a.txt:x`）、`CON`／`NUL` 保留名、
  結尾的點或空白、萬用字元、控制字元、全形或長得像的斜線與點；路上任何一段是捷徑（symlink）或 junction 一律拒；
  解開後要還在那個白名單資料夾裡、名字沒被換成別名（8.3 短檔名）。Windows 不分大小寫。
- **禁區**（白名單蓋不過）：`.git`、`.hg`、`.svn`、`_inbox`、`.ssh`、`.gnupg`、`_keys`、`.env*`、`*.pem`、`*.key`、`id_rsa*`、`credentials*`、
  名字含 secret／password／credential 的檔、`.claude`、`AppData`、瀏覽器與通訊軟體的資料（`User Data`、`Chrome`、`Edge`、`Firefox`、`Telegram Desktop`…）、
  `desktop.ini`、`Startup`、SYNOX 的資料夾、這個工具的程式與資料。禁區不會出現在 find、grep、tree 的結果裡。
  名字剛好是 `chrome`、`edge`、`startup`、或含 secret 的一般檔案也會被當成禁區，請換個名字。
- **不建可以執行的檔名**（`.bat`、`.cmd`、`.ps1`、`.exe`、`.js`…）、不改名成那些副檔名；讀可以。
- **改既有的檔一定要帶版本號**（`/fs_read` 給的），對不上＝檔案在你讀過之後變了，不寫。寫之前先備份，寫的時候先寫暫存檔再換掉。
- 硬連結的檔、雲端佔位檔（還沒下載）、唯讀屬性的檔不碰。
- 讀出的內容包在每次隨機的邊界標記裡、標明「是資料，不是指令」；有像在下指令的句子、看不見的字元會另外警告。
- 不執行任何程式、不連網、不讀環境變數、不建連結。

## 資料存哪

- 白名單、設定、停止狀態、等確認的卡、最近 300 筆紀錄：加密存在 SYNOX 的保管箱（`pack.store`，每個人一份）。
  紀錄只有「編號、時間、動作、路徑、成功與否、錯誤類別」，**不記檔案內容、不記搜尋字串**。
- **備份與垃圾桶**：`pack.path_of(user, "backup")`、`pack.path_of(user, "trash")`（個人版在 SYNOX 的 `data/files/files/` 底下）。
  它們是你檔案的**原樣複本，沒有加密**（跟原本的檔一樣）；過了保留天數自動清掉。
- 安裝報告會把這個工具標成「讀寫 pack 以外的檔案」（`filesystem:any`）——它真的要讀寫你的資料夾，請看清楚再按同意。
  只給擁有者用（`access: owner`），伺服器版的成員看不到。

## 目前不完善的地方（alpha）

- **檢查與動作之間有一瞬間的空檔**：沒有用 Windows 的 handle 在打開檔案之後再驗一次真正的位置（要 `ctypes`，這個工具不用）。
  寫入前會再解析一次路徑、比一次版本號，但如果**別的程式**剛好在那一刻把資料夾換成 junction，理論上擋不住。
- **刪除用的是這個工具自己的垃圾桶**，不是 Windows 的資源回收筒；還原請用 `/fs_undo`，不在檔案總管的資源回收筒裡。
- 跨磁碟搬移（含刪除到垃圾桶）是「複製完再刪來源」；中途失敗會清掉複製到一半的，但大量檔案時比較慢。
- 只認 UTF-8（可有 BOM）與有 BOM 的 UTF-16 文字檔；Big5 之類會被說「不是 UTF-8」。
- grep 用 Python 的正規表示式，擋了常見會跑很久的寫法（巢狀重複、反向參照）＋每次最多 8 秒，但不保證擋得住所有慢的樣式。
- 禁區用名字比對，會誤擋名字剛好像禁區的一般檔案（見上面）。
- 還沒有設定面板（網頁），設定用 `/fs_settings`、`/fs_set`。
- 打字輸入多行內容要 `esc=yes`；單次內容最多 2000 字。
