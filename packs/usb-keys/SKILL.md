# 🔑 USB 鑰匙

使用者把隨身碟登記成「鑰匙」，再選一把來鎖訊息或檔案；解開時那支隨身碟一定要插著。

## 什麼時候用
- 「我有哪些 USB 鑰匙」「哪支插著」→ `usb__keys`（要讀隨身碟，幾秒鐘）。
- 「插著哪些隨身碟」「哪支可以登記」→ `usb__drives`。
- 「用書桌那把鎖這段話：…」→ `usb__lock`，`key` 放鑰匙的名字（照 `usb__keys` 列的名字），`text` 放要鎖的原話（不要改寫）。
  回來的 `utmsg1:` 開頭那一整段原樣給使用者，不要截斷、不要改。
- 「用書桌那把鎖 1/報告.pdf」→ `usb__lock`，`key`＋`file`。`file` 寫成「資料夾編號/檔名」，照使用者說的填，不要自己猜路徑。
- 「這段 utmsg1:… 要哪把鑰匙開」「這個 .utenc 檔要哪一把」→ `usb__unlock_check`，`text` 或 `file` 二選一。它不會解開。

## 不要做的事
- **你不能解開**：解開（`/usb_unlock`）、登記、重新登記、撤銷、設定資料夾都只有使用者本人能做。使用者要解開，告訴他打
  `/usb_unlock <鎖好的訊息>`，或到 SYNOX 網頁「🔑 USB 鑰匙」的畫面按「解開」。
- **不要向使用者要密碼**，也不要叫他把密碼打在聊天裡。鑰匙要密碼時，請他到「🔑 USB 鑰匙」的畫面輸入。
- 回覆說「這把鑰匙要密碼」或「沒插著」時，照原話轉告使用者就好，不要換別把鑰匙重試。
- 不要建議使用者撤銷或重新登記鑰匙：那會讓用舊鑰匙鎖的東西永遠打不開。
