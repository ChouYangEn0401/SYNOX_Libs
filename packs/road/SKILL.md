# 🚗 路況（台灣）

## 什麼時候用
- 「國一北上林口到五股塞嗎」「國道三號南下現在怎樣」→ `road__now`，`query` 寫「國1 北 林口 五股」這種格式
  （國道、方向〔北／南／東／西〕、起點交流道、終點交流道；後面幾個可以不寫）。
- 「國道有沒有車禍」「國三南下有施工嗎」→ `road__events`，`filter` 寫「國3 南 施工」（都可以不寫）。
- 「從台北車站開車到桃園機場要多久」→ `road__eta`，`trip` 寫「台北車站 到 桃園機場」。要地圖金鑰；回覆說沒設金鑰就照原話轉告使用者，不要自己猜時間。
- 「上班的路況」「我的常用路線」→ `road__routes`。
- 使用者想存一條路線 → `road__save`（`name` 名字，`spec` 國道路段或「起點 到 終點」）；刪 → `road__rm`。
- 看設定 → `road__settings`；改設定 → `road__set`（`key` 是 provider、road、dir、unit、lines、events 其中一個）。

## 注意
- 國道路況來自高速公路局的開放資料，免金鑰；起點到終點的行車時間要 TDX 或 Google 地圖的金鑰，金鑰只能由使用者在網頁的「連接」填，不要請使用者在對話裡貼金鑰。
- 交流道名稱照高速公路局的叫法（林口、五股、泰山轉接…）；回覆說找不到時，裡面會列出這條路有哪些交流道，照那份重問一次。
- 回覆裡的時間與速度直接轉述，不要自己換算或加料。
