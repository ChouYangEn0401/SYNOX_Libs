# 🚗 路況（road）

**0.1.0-alpha.1・alpha（尚未實機驗證）**：只用假資料的自動測試跑過，還沒在真的 SYNOX／Telegram 上長時間用過。
功能先求「有」，下面「目前不完善」列了已知的毛邊。

台灣國道的即時路況（每一段的車速、旅行時間、壅塞程度）、1968 的即時事件（事故、施工、管制）、
起點到終點的開車時間（TDX 或 Google 地圖），以及「上班路線」這種常用路線一次查。

## 指令

| 指令 | 做什麼 |
|---|---|
| `/road [國道] [方向] [起點] [終點]` | 國道路段現在的車速、旅行時間、壅塞（不用金鑰）。例：`/road 國1 北 林口 五股`、`/road 國3 南`、`/road 國5`；設了預設國道只打 `/road` |
| `/road_events [國道] [方向] [關鍵字]` | 國道現在的事故、施工、管制、天候事件。例：`/road_events 國1`、`/road_events 國3 南 施工` |
| `/road_eta <起點> 到 <終點>` | 開車要多久（要 TDX 或 Google 地圖金鑰）。例：`/road_eta 台北車站 到 桃園機場`；也收「緯度,經度」 |
| `/road_routes` | 一次查全部常用路線 |
| `/road_save <名字> <內容>` | 存常用路線：國道路段（`/road_save 上班 國1 北 林口 五股`）或起點到終點（`/road_save 回家 公司 到 家`） |
| `/road_rm <名字>` | 刪掉一條常用路線 |
| `/road_settings` | 看設定、金鑰有沒有設、常用路線 |
| `/road_set <鍵> <值>` | 改一項設定（值寫「預設」＝回到預設） |

國道寫法：`國1`、`國道1號`、`國道一號`、`1`、`中山高`、`國3甲`、`五楊`（＝國道1號汐止五股高架）、`台76`。
方向：`北`／`南`／`東`／`西`（也收北上、南下、北向…）；不寫＝兩個方向都列（有寫起點終點時自己判斷方向）。
交流道照高速公路局的叫法（林口、五股、泰山轉接…）；寫錯的話回覆會列出那條路有哪些交流道。

## 設定（`/road_set <鍵> <值>`）

| 鍵（中文也收） | 值 | 預設 |
|---|---|---|
| `provider`（供應商） | `auto`（有 TDX 金鑰用 TDX，否則 Google）、`tdx`、`google` | `auto` |
| `road`（國道） | 預設國道，例 `國1`；`無`＝不設 | 不設 |
| `dir`（方向） | `北`／`南`／`東`／`西`／`全部` | 全部 |
| `unit`（單位） | `km`（公里、km/h）、`mi`（英里、mph） | `km` |
| `lines`（行數） | 一次最多列幾段／幾則（3–40）；路段太多時只列最慢的那幾段 | 12 |
| `events`（事件） | `開`／`關`：路況後面附上那一段的事故施工 | 開 |

SYNOX 網頁的工具頁還有一格唯讀的設定面板（`panel.html`）。

## 金鑰（只有 `/road_eta` 與「起點 到 終點」的常用路線要）

金鑰**不在聊天裡設**（聊天紀錄會留在 Telegram）：到 SYNOX 網頁的工具頁「🚗 路況」按「🔌 連接」填，
或在電腦上執行 `python -m synox connect road`。SYNOX 存在保管箱（密文），工具只用 `pack.secret(名字, user)` 讀，
不存進工具自己的資料、不放進回覆、不寫 log。

- **TDX**（交通部運輸資料流通服務，免費）：到 tdx.transportdata.tw 註冊會員 → 會員中心「資料服務 → API 金鑰」，
  把 Client Id、Client Secret 填進 `tdx_client_id`、`tdx_client_secret`。
- **Google 地圖**：Google Cloud Console 建專案 → 啟用「Routes API」→「憑證」建 API 金鑰，填進 `google_api_key`（要綁帳單，有免費額度）。

## 資料從哪裡來

| 功能 | 來源 | 金鑰 |
|---|---|---|
| 國道路段、車速、旅行時間、壅塞 | 高速公路局開放資料 `tisvcloud.freeway.gov.tw/history/motc20/` 的 `Section.xml`、`LiveTraffic.xml`（每分鐘更新） | 不用 |
| 事故、施工、管制、天候 | 同一處的 `LiveEvents.xml`（1968 即時事件） | 不用 |
| 起點到終點 | TDX：token → 地址轉座標 → MaaS 路徑規劃；Google：Routes API `computeRoutes`（考慮即時路況） | 要 |

XML、JSON、gzip 壓縮過的資料都讀得懂。只用 `requests`；`access: owner`（只給擁有者，伺服器版成員看不到這個工具）。

## 資料存哪

`pack.store.of(user)`（保管箱，密文；伺服器版每人一份）：設定、常用路線；另外一份 `sections` 是高速公路局路段基本資料的精簡版
（一天重抓一次，省得每次都下載）。金鑰不在這裡（在 SYNOX 的保管箱 `pack_secrets`）。

## 目前不完善（alpha）

- **TDX 的開車時間**：TDX 的路徑規劃以大眾運輸為主，開車用的參數（`pack.py` 的 `TDX_DRIVE`）是照文件寫的，還沒拿真的金鑰驗過，
  結果可能跟 Google 不同或查不到；查不到時改用 `/road_set provider google`。
- 交流道名稱要跟高速公路局的叫法一樣（可以只寫一部分）；還不認得暱稱（例如「林口 A7」）。
- 只有國道與高公局管的快速公路；省道、市區道路的路況要用 `/road_eta`（地圖供應商）看。
- 路況是「現在」的，沒有預測、沒有到時間自動提醒（要提醒可以自己用 `/remind_add` 定時打 `/road_routes`）。
- 沒資料的路段用 90 km/h 估，回覆裡會標出幾段沒資料。
