# 🎸 guitar（吉他和弦）

> **0.2.0-alpha.1：alpha（尚未實機驗證）**——只在這個 repo 的自動測試裡跑過，還沒在真的 SYNOX／Telegram 上試過。

把「吉他和弦全書」做成 SYNOX 工具：聊天裡直接查和弦、**貼一份譜就移調**、問夾 capo 怎麼彈最簡單、拿分散和弦 TAB；
網頁上有完整的面板（和弦圖、即時移調、複製）。樂理與按法資料從「吉他和弦全書」（羊ㄣ出品）搬來，組成音都由程式逐弦算過。

| 指令 | 做什麼 |
|---|---|
| `/chord <和弦…>` | 查按法：`Am7`、`D/F#`、`Bb F Gm Eb`（一次好幾個＝每個一行，橫按的附簡易按法）。一個的時候列出每根手指、組成音、其他按法 |
| `/chord_tp <移法>` ＋ 換行貼譜 | 整份譜移調。移法：`+2`、`-3`、`升2`、`降1`、`G→A`、`到 A`。不貼譜＝用上次貼的那份（可以一直換移法試） |
| `/chord_capo [格數] [譜或調]` | 夾第 0～7 格各要按幾個橫按，挑最好彈的三種；有譜就附「照那組手型彈」的譜。`/chord_capo Bb`、`/chord_capo 3`（把上次的譜改成夾第 3 格的手型） |
| `/chord_arp <和弦…> [型態]` | 分散和弦 TAB：型態 1～5（常見型 T1213121、交替型、綿密型、三拍子、簡單型）或自己寫 `T121` |
| `/chord_key <調>` | 這個調的七個和弦、最常用四個、1564／卡農／1645／6415／ii–V–I，以及「不想橫按要夾幾格」 |
| `/chord_chart [移法]` ＋ 換行貼進行 | 排成**一格一小節**的小節譜（每行 4 小節）。`| C | G D/F# | Am | F |`、`C G Am F`、譜、或 AI 看照片填的 JSON；第一行可以先寫移法（`+2`）；不貼＝用上次的譜 |

聊天打指令時，換行在進到工具之前就被併成空白了（指令照空白切參數），整份譜會變成一行：這時分不出哪行是和弦、哪行是歌詞，
`/chord_tp`、`/chord_capo` 改成「每個自己一個字、像和弦的字都照和弦移」，回覆會加一行說明。英文歌詞裡的 `A` 之類也會被當成和弦；
要保留排版、對齊歌詞，請在網頁面板貼譜。

## 譜的寫法

兩種都認得，可以混在一起：

```
前奏： G  D/F#  Em  C
G              D/F#
我想你 我想你
這是[G]一首[D]簡單的[Em]歌
```

- **和弦行**：一整行都是和弦（可以有 `|`、`(x2)`、`N.C.`、`前奏：`、`[Chorus]` 這種段落名稱）。移調後每個和弦**盡量留在原本那一欄**，歌詞還是對得上
  （聊天的字不是等寬字，看起來可能歪；複製到等寬字的地方、或用網頁面板看就對齊了）。
- **[C] 夾在歌詞裡**（ChordPro 的寫法）。
- 和弦的尾巴照原譜的寫法保留（`Cmaj7`、`CM7`、`C△7` 都不改）；只換根音和斜線後面的低音。
- 原調由程式從和弦猜（用到哪些和弦、第一個和最後一個和弦）；猜錯時用 `G→A` 這種寫法明講，或在面板改「原調」。
- 升降記號照新調寫：降記號的調（F、Bb、Eb、Ab、Db）寫 Bb、Eb…；升記號的調寫 F#、C#…。

## 小節譜（`/chord_chart`）

看到一首不會彈的歌：拍照給 AI（它照下面的格式把和弦一小節一小節填好），或自己打一段進行，就排成整齊的格子：

```
🎸 小節譜：週末的海邊｜D 調・4/4（12 小節）
和弦：D A/C# Bm G A F#m Em7 A7

【前奏】
| D        | A/C#     | Bm       | G        |
【副歌】×2
| G        | A        | F#m      | Bm       |
| Em7      | A . . A7 | D        | %        |

📋 完整的小節譜（和弦圖、移調、Capo、照片標記、列印）在網頁面板的「小節譜」分頁。
```

（格子用等寬字排；聊天的字不是等寬時可能歪一點，網頁面板的「小節譜」分頁一定對齊。）

### 打字的寫法（`parse_progression`）

| 寫法 | 意思 |
|---|---|
| `\| C \| G D/F# \| Am \| F \|` | 小節線分開，一格一小節；一格裡幾個和弦就平均分拍（`G D/F#`＝各兩拍） |
| `C G Am F` | 沒有小節線＝**一個和弦一小節** |
| `Am . . G`、`Am:3 G:1` | 指定拍數：`.`（或 `/`）＝前一個和弦多一拍；`:3`＝三拍 |
| `C / / / G / / /` | 沒有小節線、有拍子記號：照拍子排進小節 |
| `[主歌]`、`【副歌】`、`前奏：`、`Verse 1:`、單獨一行 `Chorus` | 段落 |
| `%` | 同上一小節 |
| `N.C.` | 不彈 |
| `(x2)`、`x3`、`2次`、`\|: … :\|` | 這一行重複；寫在段落名稱後面（`【副歌】×2`）＝整段重複 |
| `Key: G  Capo 2  3/4  ♩=90`、`標題：…`、`歌手：…`、`每行 5` | 最上面的資訊行 |
| 和弦一行、歌詞一行 | 和弦變成小節，下面那行歌詞照欄位分到每一小節 |
| `這是[G]一首[D]歌` | 每個和弦一小節，歌詞是它後面那段字 |

看不懂的字標成 `?` 並告訴你。Capo：**譜上寫的和弦＝夾了 capo 之後按的手型**（一般譜的寫法），聽起來的調＝寫的調＋capo。

### 小節譜的格式（JSON；AI 看譜的照片時填這個）

```json
{
  "title": "歌名", "artist": "歌手", "key": "G", "capo": 0, "time": "4/4", "tempo": 84, "bars_per_line": 4,
  "sections": [
    {"name": "主歌 A", "bars": [["C"], ["G", "D/F#"], ["Am:3", "G:1"], ["%"], ["N.C."], ["?"]],
     "lyrics": ["第一小節的詞", "", "…"]},
    {"name": "副歌", "repeat": 2, "bars": [["F"], ["G"], ["Em7"], ["Am"]]}
  ],
  "notes": "副歌第二次漸強",
  "image": {"marks": [{"x": 0.12, "y": 0.30, "chord": "Am"}]}
}
```

| 欄位 | 說明 |
|---|---|
| `sections[].bars` | **一格＝一小節＝一個陣列**，放 1～4 個和弦。沒寫拍數＝平均分；`"Am:3"`＝三拍。也可以寫成字串 `"Am . . G"`。 |
| 特別的格 | `"%"` 同上一小節、`"N.C."` 不彈、`"?"` 看不清楚（不要猜） |
| `sections[].name`／`repeat` | 段落名稱（可以空白）；整段重複幾次（2～16，沒有就不寫） |
| `sections[].lyrics` | 選填：跟 `bars` 一樣長，每小節一小段詞 |
| `key` | 譜上寫的調（`G`、`Am`）；空白＝程式自己猜 |
| `capo` | 譜上寫的 capo（0～11）；和弦照譜上寫的手型 |
| `time`／`tempo`／`bars_per_line` | 拍號（`4/4`、`3/4`、`6/8`）、速度（選填）、每行幾小節（1～8，預設 4） |
| `image.marks` | 選填：每個和弦在照片上的位置，`x`、`y` 是 0～1 的比例（左上角是 0,0）；面板選同一張照片就會把（移調後的）和弦標上去 |

程式收到後會整理（`normalize_chart`：大小、範圍、和弦名稱都檢查；看不懂的和弦換成 `?` 並列出來），JSON 外面包 ```json 圍欄或多一個逗號都沒關係。
移調（`/chord_chart +2`、`G→A`、`到 A`）跟 `/chord_tp` 同一套：升降記號照新調寫，照片標記也一起移。

### 獨立樣板頁（`docs/guitar/chart_template.html`）

不用 SYNOX 也能用的一頁：不連網、系統字型、手機寬度可用、深淺色都有、可以列印。功能跟面板的「小節譜」分頁一樣（同一份程式）。

- **資料注入點**：頁面裡 `<script type="application/json" id="chart-data">…</script>` 那一段，換成上面格式的 JSON 就是一份新譜（JSON 裡的 `</` 寫成 `<\/`）。
  在 claude.ai／Claude Code 裡可以讓 Claude 填好這段、發佈成 Artifact。
- 和弦按法資料（`id="chord-lib"`）與共用的 CSS／HTML／JS 是從 `panel.html`、`pack.py` 產生的：改了它們之後跑
  `python3 scripts/guitar_template.py`（`--check` 只檢查有沒有跟上；不需要 SYNOX）。
- 它放在 `docs/` 而不是工具資料夾：不會被打包進 `.synoxpack`，也不受面板的規則（M5）管。

## 網頁面板

SYNOX 網頁的工具頁有「吉他和弦」面板（`panel.html`，資料來自 `GET /api/packs/guitar/data`：按法資料＋你上次貼的譜）：

- **貼譜移調**：貼上就即時移調，`−1`／`＋1` 或直接選新調；列出 capo 的好彈選擇（按一下就看那組手型的譜）；
  下面畫出這份譜用到的每個和弦（可以勾「優先用簡易按法」）；一鍵複製。
- **查和弦**：打名稱或點根音＋種類，看每一種按法的和弦圖（綠色＝根音）。
- **小節譜**：上次 `/chord_chart` 的譜（沒有就用上次貼的譜）排成格子；`−1`／`＋1` 移調、選 Capo（換成另一組手型）、每行幾小節；
  點小節裡的和弦跳到它的和弦圖；可以直接在上面打一段進行即時重排；複製文字、列印。
  譜有 `image.marks` 時可以選那張照片，和弦會標在照片上（照片只讀進這個頁面的記憶體，不上傳、不存）。
- **分散和弦**：打和弦、選型態，出 TAB。

## 資料

- 只存兩樣東西：**最後一次貼的譜**（`/chord_tp`、`/chord_capo`、`/chord_chart` 帶譜的時候，最多 12000 字）與**最後一份小節譜**（`/chord_chart`，最多 512 小節），
  放保管箱（`pack.store.of(user)`，密文；伺服器版每人一份）。目的是讓「`/chord_tp +1`」不用再貼一次、面板看得到小節譜。照片不會傳到伺服器。
- 不連網、不碰檔案、不開別的程式（`capabilities: []`）。

## 已知限制

- SYNOX 會把 `名字=值` 這種字當成指令的欄位；譜裡剛好有 `=` 連著字（很少見）時，請讓 AI 幫你叫，或貼到網頁面板。
- 自動排出來的按法（標「自動」）音一定對，但手指只是建議。
- 延伸和弦（`C13`、`G7b9`…）移調照樣對；查按法時先給最接近的（`C7`、`G7`），會寫出來。
- 面板裡沒收錄的斜線和弦，先畫原本的和弦、說明低音要改彈哪個音；聊天的 `/chord` 會自動排完整按法。

**個人版與伺服器版**：伺服器版每人一份，別人的指令、面板、AI 都看不到你貼的譜（伺服器的管理者有主金鑰，[ADR-0006](../../docs/adr/0006-personal-and-server-mode.md)）。
