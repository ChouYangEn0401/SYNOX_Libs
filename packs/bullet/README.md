# • bullet（子彈筆記）

照 Ryder Carroll 的 Bullet Journal：快速記錄（rapid logging）、每日記錄、月誌、遷移、主題清單。

| 指令 | 做什麼 |
|---|---|
| `/bj <內容>` | 記一筆到今天。開頭 `•` `*` `.` ＝任務、`○` `o` ＝事件、`–` `-` ＝筆記；沒寫就看字猜（有時間或「開會、聚餐…」→ 事件；「買、繳、記得…」→ 任務；其他 → 筆記）。`kind=task\|event\|note` 指定、`col=書單` 記進主題清單、`date=2026-11-02` 補記 |
| `/bj_today` | 今天的每日記錄 |
| `/bj_month [YYYY-MM]` | 月誌：有記東西的每一天（事件、任務完成數、筆記數）＋這個月還沒做完的任務 |
| `/bj_migrate` | 遷移：以前沒做完的任務一件一件問，按鈕選「➡️ 搬到今天／× 已完成／✗ 不做了／略過」；同一張卡原地換下一件，24 小時後過期 |
| `/bj_done <編號>` | 任務打勾 |
| `/bj_rm <編號>` | 刪掉一筆（記錯、猜錯分類時用） |
| `/bj_col [名稱]` | 主題清單：不寫＝列出全部，寫名稱＝看那一本 |

符號：`•` 待做、`×` 完成、`>` 已遷移（新的那筆記在今天，記著從哪一筆搬來）、`✗` 不做了、`○` 事件、`–` 筆記。
主題清單裡的東西不會混進每日記錄和月誌。

網頁介面的工具頁有「今天」面板（`GET /api/packs/bullet/today`）。

資料：`data/bullet.json.enc`（保管箱加密；伺服器版每人一份）。不連網、不開檔、不開別的程式（`capabilities: []`）。
